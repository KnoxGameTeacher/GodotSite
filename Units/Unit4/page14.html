Section 14: Gold Economy

Earn gold from enemies and spend it on towers

Section Progress: 0%
1

One Number for Money

  • An economy needs one number every script can reach: how much gold the player has. That number belongs in Global, next to the wave and the fence.
  • Open scripts/global.gd. It now reads:

extends Node

var current_wave = 0
var fence_durability = 20
var gold = 100
  • Gold is in Global for the same reason current_wave and fence_durability do. Every script that needs it already knows Global.
  • Mine is 100 starting gold, but yours can be anything. Your GDD decides what the player opens with.
  • Players need a starting amount of gold. Towers cost gold and kills pay gold, but the first tower has to come from somewhere.

Kills Pay

  • Kills are the income. Add an export to scripts/enemy.gd, next to damage:
@export var gold_reward = 10
  • Change take_damage so the killing blow pays:

func take_damage(amount, ignores_armor = false):
	var effective = amount
	if not ignores_armor:
		effective = amount * (1.0 - clampf(armor, 0.0, 1.0))
	health -= effective
	if health <= 0:
		Global.gold += gold_reward
		print("Gold: ", Global.gold)
		get_parent().queue_free()
  • Mine is 10 gold per kill, but this depends on your game's design.
  • Different enemy types pay different rewards. Set gold_reward per scene in the Inspector, the same way you set health and damage.
  • The reward sits inside the health check, so only the killing blow pays. Hits that do not kill pay nothing.
  • The armor lines from Section 11 stay, so the gold lines join them instead of replacing them.
  • Burn kills pay too, since burn damage goes through take_damage.
  • There is no HUD yet, so the print is where we'll check if it's working. Every kill reports the new total.
  • Waves pay too. Open scripts/wave_manager.gd and add the bonus to the completion check from Section 12:

func _process(delta):
	if wave_active and spawning_done and get_tree().get_nodes_in_group("enemies").is_empty():
		wave_active = false
		Global.current_wave += 1
		Global.gold += 25
		print("Wave complete")
  • Two incomes, then: kills pay per enemy, and every completed wave pays a flat 25.
  • The bonus is a flat 25 every wave, not scaled by cycle, so it matters most early, when the first towers are still unaffordable. This is something you could consider adjusting in your personal project.
Figure 14.2: Gold reward on enemy death

Every Tower Has a Price

  • Spending needs prices, and prices belong with the thing being bought. Add an export to scripts/tower.gd:
@export var cost = 50
  • Mine is 50 gold per tower base, but yours can be anything. These are set in the inspector so this value is the default.
  • Each tower scene carries its own cost, so types are priced independently. A cheap fast tower and an expensive strong tower are just two scenes with different exports.
  • Tower already carries its class name from Section 8, the same trick as PlacementZone in Section 7 and Enemy in Section 9, so no class_name line is needed here. That is what lets placement.gd treat the ghost as a Tower and read its cost.

Keys Pick the Tower

  • Selection needs at least two tower scenes. If you only have one, duplicate it in the FileSystem dock, change its exports and model, and save it under a new name. Each type is its own scene with its own cost.
  • Open scripts/placement.gd and replace the tower_scene export with an array:
@export var tower_scenes: Array[PackedScene]
  • This replaces the old tower_scene export. The old slot is gone, so drag each tower scene into the new array in the Inspector, in key order. Slot 0 is key 1, slot 1 is key 2, slot 2 is key 3.
  • Track the selection:

var selected_index = 0
  • preview is already a Tower from Section 8, so no retype is needed here. Only the selection tracking is new.
  • Add three actions in Project Settings, Input Map: select_tower_1 on key 1, select_tower_2 on key 2, select_tower_3 on key 3.
  • Add select_tower to scripts/placement.gd:

func select_tower(index):
	if index >= tower_scenes.size():
		return
	selected_index = index
	if is_instance_valid(preview):
		preview.queue_free()
	preview = tower_scenes[selected_index].instantiate() as Tower
	make_ghost(preview)
	add_child(preview)
	preview.set_process(false)
	var ring = preview.get_node("RangeRing") as MeshInstance3D
	ring.visible = true
	ring.scale = Vector3(preview.attack_range, 1, preview.attack_range)
	if hovered_zone != null:
		preview.global_position = hovered_zone.global_position
		preview.visible = true
	else:
		preview.visible = false
	print("Selected ", preview.name, " cost ", preview.cost)
  • "as Tower" casts the new node to Tower. Without it, Godot only knows the new node is a Node, and cost is not available.
  • add_child comes before set_process, the same order Section 8 taught you.
  • The rebuilt preview is a fresh ghost, so its ring starts hidden again. Show and scale it here, the same lines as Section 8.
  • Because the ring scales from the new preview's attack_range, the circle changes size when you switch towers, so each type shows its own reach.
  • If you are already hovering a zone, the new ghost snaps to it at once instead of waiting for the next hover.
  • The print is the selection feedback. The name comes from your tower scene's root name, so name your scenes well.
  • Extend _unhandled_input with the keys. The mouse part is unchanged from Section 7:

func _unhandled_input(event):
	if event.is_action_pressed("select_tower_1"):
		select_tower(0)
	elif event.is_action_pressed("select_tower_2"):
		select_tower(1)
	elif event.is_action_pressed("select_tower_3"):
		select_tower(2)
	if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
		try_place()
  • Replace _ready with this. The old preview building lines go away, since select_tower builds the first ghost:

func _ready():
	select_tower(0)
	call_deferred("_connect_zones")
  • Finally, replace try_place with the guarded version:

func try_place():
	if hovered_zone == null:
		return
	if hovered_zone.occupied:
		return
	if Global.gold < preview.cost:
		print("Not enough gold")
		return
	Global.gold -= preview.cost
	var tower = tower_scenes[selected_index].instantiate()
	add_child(tower)
	tower.global_position = hovered_zone.global_position
	hovered_zone.occupied = true
	preview.visible = false
	hovered_zone = null
  • The guard comes before the deduction. A failed placement should not charge you.
  • The deduction comes before the placement, so gold is spent when the tower lands.
  • The placed tower is a fresh instance, not the ghost. The ghost stays a ghost for the next hover.

Testing Gold

  • Press F6. Press 1, 2, 3 to switch towers. The Output panel prints each selection and its cost.
  • Hover a zone with each tower. The range circle changes size with the tower, since each type shows its own reach.
  • Place a tower. Your gold drops by that tower's cost.
  • Try to place with less gold than the cost. The tower does not place, and the Output panel prints Not enough gold.
  • Kill enemies. Each kill adds that enemy's gold_reward, and the Output panel prints your new total.
  • Complete a wave. Gold jumps by 25 on top of the kill rewards.
  • Save for the expensive tower. Place cheap towers early, earn gold from kills, and buy the stronger type when you can afford it.
  • Play a full wave with the economy on. Towers cost gold, kills pay gold, and the wave still completes when the group empties.
💡 If the economy will not work:
  • Gold never increases: the gold_reward line is missing from take_damage. Check the kill path in enemy.gd.
  • No wave-clear bonus: the gold line is missing from the completion check in wave_manager.gd. Check _process.
  • Towers place with 0 gold: the cost guard is missing from try_place, or the deduction runs before the guard. Check the guard comes first.
  • Wrong tower places: the tower_scenes order does not match your keys. Check slot 0 is key 1, slot 1 is key 2, slot 2 is key 3.
  • Error about cost on a Node: the as Tower cast is missing from select_tower, or the Section 8 preview retype never happened. Check both.
  • Ghost never changes: select_tower is never called, or the actions are missing from the Input Map. Check _unhandled_input and the action names.
  • Error when hovering a zone: the tower_scenes array is empty, so no ghost exists. Drag a tower scene into a slot.
  • Selected tower has the wrong cost: the cost export is on the wrong tower scene, or the scene was never saved after setting it. Check the Inspector on each tower scene.
  • Ring never shows on the new ghost: the ring lines are missing from select_tower. Check the show and scale lines.
  • Game starts with nothing to spend: Global.gold starts at 0. Give it a starting amount in global.gd.
