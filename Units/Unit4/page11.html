Section 11: Splash Damage and Counters

Add splash damage, armor counters, and burns to combat

Section Progress: 0%
1

Not Every Hit Lands the Same

  • So far every hit deals full damage. A tank enemy should shrug off weak hits, and some other tower should be a counter.
  • Add an armor export to scripts/enemy.gd:

@export var armor = 0.0
  • Armor is the fraction of normal damage blocked, from 0 to 1. An armor of 0.5 blocks half, while an armor of 0 blocks nothing.
  • Rework take_damage in scripts/enemy.gd to use it:

func take_damage(amount, ignores_armor = false):
	var effective = amount
	if not ignores_armor:
		effective = amount * (1.0 - clampf(armor, 0.0, 1.0))
	health -= effective
	if health <= 0:
		get_parent().queue_free()
  • clampf keeps armor between 0 and 1. Above 1, hits would heal instead of hurt. That's an interesting mechanic, but not our goal.
  • Existing enemies are unchanged, the armor defaults to 0, so old scenes take full damage until you set armor on them.
  • Duplicate an enemy scene for an armored type and set its armor to 0.5. Shoot it with your normal tower and count hits to kill, then shoot the unarmored type. The armored one should take twice as many hits.

One Shot, Many Targets

  • A swarm laughs at single-target damage. The answer is a shot that hurts everything near where it lands.
  • Add a splash export to scripts/projectile.gd:

@export var splash_radius = 0.0
  • A radius of 0 means direct damage only, so old projectile scenes behave exactly as before.
  • Replace the hit handler in scripts/projectile.gd:

func _on_body_entered(body):
	if body is Enemy:
		if splash_radius > 0.0:
			for node in get_tree().get_nodes_in_group("enemies"):
				var enemy = node as Enemy
				if global_position.distance_to(enemy.global_position) <= splash_radius:
					enemy.take_damage(damage)
		else:
			body.take_damage(damage)
		queue_free()
  • Splash definition is on the projectile scene, so the tower code does not change. A splash tower is a tower whose projectile scene has a radius set in the Inspector.
  • The radius is measured from the impact point, and the direct target is inside it, so it takes damage with the rest.
  • The cast to Enemy is the Section 9 trick again. The group hands back plain nodes, and take_damage only exists on Enemy.
  • Duplicate a projectile scene for a splash type and set its radius to 1.5. Swap the splash tower's projectile scene to it in the Inspector, spawn a swarm, and watch one shot wound several enemies.
  • If you want a different look for this tower's projectile, swap its model for the new look. Since they are separate scenes, changing one projectile model leaves the others.

The Burn That Ignores Armor

  • Armor beats normal damage, so something must beat armor. That something is a burn: damage over time that ignores armor entirely.
  • Add burn state and a starter to scripts/enemy.gd:

var burn_dps = 0.0
var burn_time = 0.0

func start_burn(dps, duration):
	burn_dps = dps
	burn_time = duration
  • Add the burn tick at the top of _process in scripts/enemy.gd, before movement:

	if burn_time > 0.0:
		burn_time -= delta
		take_damage(burn_dps * delta, true)
  • burn_dps times delta means it will tick consistently.
  • The second argument is true, so armor never reduces burn damage. That is what makes burn the armor answer.
  • A fresh burn replaces the old one. Starting a burn while burning restarts the timer at the new values.
  • Add burn exports to scripts/projectile.gd:

@export var burn_dps = 0.0
@export var burn_duration = 0.0
  • Extend the hit handler in scripts/projectile.gd so burn is checked first:

func _on_body_entered(body):
	if body is Enemy:
		if burn_dps > 0.0:
			body.start_burn(burn_dps, burn_duration)
		elif splash_radius > 0.0:
			for node in get_tree().get_nodes_in_group("enemies"):
				var enemy = node as Enemy
				if global_position.distance_to(enemy.global_position) <= splash_radius:
					enemy.take_damage(damage)
		else:
			body.take_damage(damage)
		queue_free()
  • One job per projectile. A burn shot stings one enemy, a splash shot wounds a group, a direct shot hits one target. The handler checks burn first, so a shot with both would never splash. Pick one.
  • Duplicate a projectile scene for a burn projectile type and set burn_dps to 5 and burn_duration to 3. Swap your tower's projectile scene to it, shoot your armored type, and watch the burn tick the health down.

Testing Counters

  • Play the triangle. Armor beats normal damage, burn beats armor, splash beats swarms. No one shot is the always right pick.
  • Normal shots against your armored type take twice as many hits at armor 0.5. Burn shots against the same type melt it at full rate.
  • Splash shots against a swarm wound several enemies at once. Direct shots against the same swarm kill one at a time.
  • Swap your tower's projectile scene in the Inspector between tests. Multi-tower selection arrives later. For now, one tower at a time proves each counter.
💡 If the new damage will not work:
  • Armor does nothing: take_damage never gained the second number, or the armored scene's armor export is still 0. Check the signature and the scene.
  • Armor blocks everything: armor is 1 or above. Keep it between 0 and 1.
  • Splash hits one enemy: splash_radius is 0, or the loop checks the wrong group. Check the radius and the enemies group.
  • Splash hits everything on the map: the radius is too large, or the distance check is missing. Check both.
  • Burn never ends: burn_time never decreases. Check the tick sits in _process and subtracts delta.
  • Burn and splash on one shot: the handler checks burn first, so splash never runs. Pick one job per projectile.
  • Error about take_damage arguments: a call passes two numbers to the old one-number function, or one number where two are needed. Check the signature has the default.
