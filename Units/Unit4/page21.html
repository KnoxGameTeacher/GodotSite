Instructions Before the First Wave

  • We know how to play our game, but a new player does not.
  • Add a Panel named "InstructionsPanel" to the HUD CanvasLayer, and add a Label child to it.
  • Write one line per control in the label. Mine reads:

Space or Start Wave: begin a wave.
1, 2, 3 or tower buttons: pick a tower.
Click a zone: place it.
Click a tower, then U to upgrade or S to sell.
Esc: pause.
  • Add a Button named "GotItButton" to the panel, and set its text to Got it.
  • Add the reference and the handler to scripts/hud.gd:

@onready var instructions_panel = $InstructionsPanel

func _on_got_it_button_pressed():
	click_sound.play()
	instructions_panel.visible = false
  • The panel shows at the beginning of every run.
  • The panel hides on clicking the button.

Help on Hover

  • Select each HUD button. In the Inspector, find Tooltip, Text, and type what the button does.
  • StartWaveButton: Begin the next wave.
  • Tower buttons: name, cost, and damage. Mine says "Daisy Pot. Costs 25 gold. Deals 10 damage." Yours will differ.
  • UpgradeButton: Upgrade the selected tower.
  • SellButton: Sell the selected tower for 70 percent of its cost.
  • Tooltips appear when the mouse rests on a control. They are Inspector text.
  • Tooltips only work on Controls. Buttons, sliders, and checkboxes are Controls, so every menu control can have one.

Damage You Can See

  • Hits need feedback, or damage is invisible until the enemy falls. A quick scale pop on the model says the hit landed.
  • Change take_damage in scripts/enemy.gd, so the full function now reads:

func take_damage(amount, ignores_armor = false):
	var effective = amount
	if not ignores_armor:
		effective = amount * (1.0 - clampf(armor, 0.0, 1.0))
	health -= effective
	if health <= 0:
		Global.gold += gold_reward
		Global.gold_earned += gold_reward
		Global.kills += 1
		print("Gold: ", Global.gold)
		get_parent().queue_free()
	elif effective >= 1.0:
		var model = get_node("Model")
		var base = model.scale
		var tween = create_tween()
		tween.tween_property(model, "scale", base * 1.5, 0.05)
		tween.tween_property(model, "scale", base, 0.1)
  • The gold, kills, and earnings lines stay, so the pop joins them instead of replacing them.
  • The pop only fires for hits of at least 1 damage, so burn ticks skip it, since each tick is a fraction of a point.
  • base captures the model's scale first, so enemies with scaled models pop back to their own size, not to 1.
  • Splash hits pop too, since splash goes through take_damage.
  • The tween dies with the enemy on a killing blow, so the pop only runs on survivors.

Glow and Flash

  • Two more material tricks tell the player what an enemy is going through. A burning enemy glows orange, and a hit enemy flashes white.
  • material_override only affects the node it is set on, never its children. A model built from parts keeps its materials on the part meshes, so the override has to reach each mesh. Collect the meshes once, then set the override on each one.
  • Make the two materials as resources, the same way Section 20 made the select material. In the FileSystem dock, create two StandardMaterial3D resources in the materials folder, and name them burn_material.tres and flash_material.tres.
  • Set burn_material.tres in the Inspector: Albedo Color orange (1.0, 0.4, 0.0), Emission Enabled, Emission orange (1.0, 0.3, 0.0). Leave Energy Multiplier at 1.0, the flicker sets it while burning.
  • Set flash_material.tres in the Inspector: Albedo Color white, Emission Enabled, Emission white.
  • Reference both materials at the top of scripts/enemy.gd:

const BURN_MATERIAL = preload("res://materials/burn_material.tres")
const FLASH_MATERIAL = preload("res://materials/flash_material.tres")
  • Add the timer state to scripts/enemy.gd, beside the burn state:

var burn_dps = 0.0
var burn_time = 0.0
var flash_time = 0.0
var model_meshes: Array[MeshInstance3D] = []
  • Collect the meshes in _ready in scripts/enemy.gd:

func _ready():
	health = max_health
	_collect_meshes(get_node("Model"))
  • Add the collector to scripts/enemy.gd. It walks the model and keeps every mesh it finds, the same recursive walk as make_ghost in Section 6:

func _collect_meshes(node: Node):
	if node is MeshInstance3D:
		model_meshes.append(node)
	for child in node.get_children():
		_collect_meshes(child)
  • Trigger the flash in take_damage, in the same branch as the pop:

	elif effective >= 1.0:
		flash_time = 0.08
		var model = get_node("Model")
		var base = model.scale
  • Set the override with a helper, so the resolve block stays short:

func _set_model_material(material: Material):
	for mesh in model_meshes:
		mesh.material_override = material
  • Resolve the material at the end of _process in scripts/enemy.gd, after movement:

	else:
		follow.progress += move_speed * delta
	if flash_time > 0.0:
		flash_time -= delta
	if flash_time > 0.0:
		_set_model_material(FLASH_MATERIAL)
	elif burn_time > 0.0:
		_set_model_material(BURN_MATERIAL)
		BURN_MATERIAL.emission_energy_multiplier = 1.0 + sin(Time.get_ticks_msec() / 80.0) * 0.5
	else:
		_set_model_material(null)
  • Flash wins while it lasts, burn shows while burning, and nothing shows otherwise.
  • Flash lasts 0.08 seconds, about five frames. Long enough to read, short enough to feel instant.
  • Burn ticks skip the flash, since each tick is under 1 damage, the same threshold as the pop.
  • Burning enemies pulse together, since the flicker reads global time.
  • The two materials are shared, one file each, so every enemy uses the same pair. The flicker still works, since it reads the clock and every burning enemy sets the same energy.
  • material_override replaces each mesh's own material while it lasts, and null brings the original back. Nothing about the model is changed for good.

Health You Can See

  • Add a Sprite3D child to the enemy scene root and name it "HealthBar". Move it above the model, centered on the root. Mine sits at y 1.2, yours can be anything.
  • In the Inspector, set Billboard to Enabled, so the bar faces the camera on its own. Billboard is off by default, and without it the sprite sits flat like any 3D object and reads edge-on from the side.
  • Add a bar reference to scripts/enemy.gd:

@onready var bar_sprite = $HealthBar
  • Add the image and texture state to scripts/enemy.gd, beside the flash state:

var flash_time = 0.0
var bar_image: Image
var bar_texture: ImageTexture
  • Set the bar up in _ready in scripts/enemy.gd:

	_collect_meshes(get_node("Model"))
	bar_image = Image.create(64, 8, false, Image.FORMAT_RGBA8)
	bar_texture = ImageTexture.create_from_image(bar_image)
	bar_sprite.texture = bar_texture
	bar_sprite.pixel_size = 0.02
	update_health_bar()
  • Add the update function to scripts/enemy.gd:

func update_health_bar():
	bar_image.fill(Color(0.15, 0.15, 0.15, 1.0))
	var width = int(ceil(64.0 * health / max_health))
	bar_image.fill_rect(Rect2i(0, 0, width, 8), Color(0.2, 0.8, 0.2))
	bar_texture.update(bar_image)
	bar_sprite.visible = health < max_health
  • Call it from take_damage, right after health drops:

	health -= effective
	update_health_bar()
	if health <= 0:
  • Pixel size 0.02 makes 64 pixels about 1.28 units wide. Mine is 0.02, yours can be anything.
  • ceil rounds up, so even 1 health shows a sliver of bar.
  • The bar hides at full health, so undamaged enemies carry no clutter.
  • The texture updates in place, so no new texture is made per hit.
  • The bar is a child of the enemy root, so it dies with the enemy.

Testing Instructions and Feedback

  • Start the game. The instructions panel shows. Press Got it. It hides.
  • Hover each HUD button. Its tooltip appears.
  • Hit an enemy. It flashes white and its model pops, then both settle back.
  • Burn an enemy. It does not jitter, since each burn tick is under 1 damage.
  • Set a projectile's burn_dps and burn_duration, then hit an enemy. It glows orange and pulses while burning, and the glow stops when the burn runs out.
  • Splash a swarm. Every enemy in the radius pops.
  • Damage an enemy without killing it. A bar appears above it and shrinks as its health drops. At full health there is no bar.
  • Kill an enemy. Its bar goes with it.
💡 If the polish will not play:
  • Instructions never hide: the Got it button's pressed signal is not connected. Check the connections.
  • Tooltips never appear: tooltip_text is empty, or the mouse moves too fast. Hover and hold still.
  • No pop on hit: the elif never runs, or the Model path is wrong. Check take_damage and the Model node name.
  • Enemy pops constantly while burning: the threshold is missing. Check effective >= 1.0.
  • Enemy stays big after a hit: the second tween is missing. Check the tween back to base.
  • No orange glow while burning: the burn material file is missing, its preload path is wrong, or the resolve block is missing from _process. Check the FileSystem dock and the preload line.
  • Flash never shows: flash_time never set in the elif, the flash material file is missing, or the resolve block is missing. Check all three.
  • Neither effect shows: _collect_meshes never ran in _ready, so the mesh list is empty. Check the _ready call.
  • Script errors on load: a preload path is wrong. Check the file names and the materials folder.
  • Glow stays after burning ends: the resolve block never reaches its else. Check the end of _process.
  • Bar never shows: the HealthBar node is missing, or update_health_bar never runs. Check the node and the take_damage call.
  • Bar never shrinks: update_health_bar is not called after health changes. Check the take_damage call.
  • Bar looks empty on a living enemy: width math rounds down to zero. Check the ceil line.
