Section 17: Volume and Settings

Add a volume slider, a mute checkbox, and a settings dictionary

What is a dictionary?

A dictionary is a collection where every value has a name, called a key. You ask for a value by its key instead of its position: settings["master_volume"] gives back 1.0, and settings["muted"] gives back false. Keys are usually strings, and values can be numbers, booleans, strings, or even another dictionary.

So far you have stored one value per variable, like gold or current_wave, and lists of things in Arrays, like tower_scenes, where you count positions to find an item. A dictionary bundles several named values into one variable, so settings carries the whole preferences block together. One variable, many values, each found by name, and the whole block can be passed around or saved as a unit.

Controls on the Panel

  • Add an HSlider node named "VolumeSlider" and a CheckBox named "MuteCheckbox" to the pause panel.
  • Add a settings dictionary to scripts/main.gd, this will go where variables usually sit:

var settings = {
	"master_volume": 1.0,
	"muted": false
}
  • Add slider and checkbox references to scripts/main.gd:

@onready var volume_slider = $PauseMenu/Panel/VolumeSlider
@onready var mute_checkbox = $PauseMenu/Panel/MuteCheckbox
  • The paths follow the node tree. PauseMenu holds the panel, and the panel holds the controls.
  • We use the dictionary to keep every preference in one place. Controls change it, and later steps read it.
  • master_volume starts at 1.0, which is full volume. muted starts at false, which means sound is on.

One Bus to Rule Them

  • Connect the slider's value_changed signal and the checkbox's toggled signal, and add the handlers to scripts/main.gd:

func _on_volume_slider_value_changed(value):
	settings["master_volume"] = value
	AudioServer.set_bus_volume_db(0, linear_to_db(maxf(value, 0.0001)))

func _on_mute_checkbox_toggled(toggled_on):
	settings["muted"] = toggled_on
	AudioServer.set_bus_mute(0, toggled_on)
  • Bus 0 is always the Master bus, so you do not need any audio setup for this to work.
  • maxf keeps the value above zero, because the log of zero is undefined and the bus would break, leading to a crash.
Figure 17.2: Volume signals connected to handlers

Testing Volume

  • Drag VolumeSlider, every sound should get quieter. Mute silences everything.
  • Check MuteCheckbox, then uncheck it. Every sound stops, then returns.
  • Volume resets when you reopen the game. Settings only last while the game runs for now, Section 18 we'll cover saving them.
💡 If the volume will not work:
  • Slider moves but nothing changes: the value_changed signal is not connected. Check the VolumeSlider connections.
  • Mute does nothing: the toggled signal is not connected. Check the MuteCheckbox connections.
  • Sounds ignore the slider: the player is on a different bus. Check the Bus property. Master is the default.
  • Volume resets on reopen: that is expected until Section 18. Settings live only while the game runs.
