Section 19: High Score and Game Over

Track persistent high scores, count kills, and end the run

Section Progress: 0%
1

The Best Run So Far

  • The score right now is the waves you survived. If the fence falls on wave 3, your score is 2, because current_wave counts the waves you finished.
  • Add the record and the kill counts to scripts/global.gd, beside the other Global numbers:

var high_score = 0
var best_kills = 0
var kills = 0
  • high_score is the best run ever. best_kills is the kills from that run, the tiebreaker. kills counts this run only.
  • Count kills in the kill branch of take_damage in scripts/enemy.gd, beside the gold pay:

	if health <= 0:
		Global.gold += gold_reward
		Global.gold_earned += gold_reward
		Global.kills += 1
		print("Gold: ", Global.gold)
		get_parent().queue_free()
  • Kills count through take_damage, so direct hits, splash, and burn all count the same way.
  • Add a game over handler to scripts/main.gd:

func on_game_over():
	print("Game Over")
	var score = Global.current_wave
	if score > Global.high_score:
		Global.high_score = score
		Global.best_kills = Global.kills
		save_high_score()
		print("New high score: ", score)
	elif score == Global.high_score and Global.kills > Global.best_kills:
		Global.best_kills = Global.kills
		save_high_score()
		print("New best kills: ", Global.kills)
	else:
		print("Best: ", Global.high_score)
	hud.show_game_over(score, Global.kills, Global.high_score, Global.best_kills)
	game_over_sound.play()
	get_tree().paused = true
  • A better wave count replaces the record outright, and the kills from that run become the new tiebreaker.
  • A tied wave count only replaces the record when this run had more kills.
  • Only a better run writes the file. An unchanged record needs no save.
  • Pausing stops the wave behind the panel, so the summary normally cannot fire after game over.
  • Pause is the first defense, not the only one. The wave-clear check must also tell a cleared wave from a lost one. Add one condition to the check in scripts/wave_manager.gd, in _process:

	if wave_active and spawning_done and Global.fence_durability > 0 and get_tree().get_nodes_in_group("enemies").is_empty():
		wave_active = false
		Global.current_wave += 1
		Global.gold += 25
		hud.show_wave_summary()
		print("Wave complete")
  • A fallen fence means the wave is lost, no matter how empty the enemies group gets. Without this condition, towers mopping up after game over would trigger the summary as if the wave were cleared.
  • The check already has the gold and summary lines from Sections 14 and 15. Only the fence condition is new.
  • The panel needs no Always mode, since it has no buttons, it only shows.
  • Hook the handler into the enemy camp block in scripts/enemy.gd. Replace the Game Over print with a call to the main scene:

# In the camp block, where the fence falls:
	get_tree().current_scene.on_game_over()
  • current_scene is the main scene root, no matter how deep the enemy sits. No parent chain needed.
  • The fence guard already stops repeat calls. Once the fence hits zero, the guard blocks every later camp tick, so game over fires exactly once.
  • Add an AudioStreamPlayer to your main scene and name it "GameOverSound". Drag your game over sound into its Stream property, and add the reference to scripts/main.gd:

@onready var game_over_sound = $GameOverSound
  • The sound lives on the main scene, since game over belongs to the run, not to any one enemy.

A Record, Not a Run

  • The main save holds a run in progress. A game over save would store a dead fence, so the record needs its own file. Progress is saved by the player, while records are saved by the game.
  • Add the path and the two functions to scripts/main.gd. They reuse the Section 18 pattern: FileAccess, JSON, and .get with a default:

const HIGH_SCORE_PATH = "user://highscore.json"

func save_high_score():
	var file = FileAccess.open(HIGH_SCORE_PATH, FileAccess.WRITE)
	file.store_string(JSON.stringify({"high_score": Global.high_score, "best_kills": Global.best_kills}))
	file.close()

func load_high_score():
	if not FileAccess.file_exists(HIGH_SCORE_PATH):
		return
	var file = FileAccess.open(HIGH_SCORE_PATH, FileAccess.READ)
	var data = JSON.parse_string(file.get_as_text())
	file.close()
	if data == null:
		return
	Global.high_score = data.get("high_score", 0)
	Global.best_kills = data.get("best_kills", 0)
  • Load the record when the game starts, and reset this run's kills. Add _ready to scripts/main.gd:

func _ready():
	Global.kills = 0
	load_high_score()
  • Kills count this run only, so _ready resets them to zero before the first wave.
  • Loading with no file does nothing, so the first ever run starts at zero with no error.

The Final Tally

  • Add a Panel named "GameOverPanel" to the HUD CanvasLayer, and turn off Visible so it starts hidden. Add three Labels to it: ScoreLabel, KillLabel, and BestLabel.
  • Add the references and a show function to scripts/hud.gd:

@onready var game_over_panel = $GameOverPanel
@onready var score_label = $GameOverPanel/ScoreLabel
@onready var kill_label = $GameOverPanel/KillLabel
@onready var best_label = $GameOverPanel/BestLabel

func show_game_over(score, kills, best, best_kills):
	score_label.text = "Waves survived: " + str(score)
	kill_label.text = "Enemies Killed: " + str(kills)
	best_label.text = "Best: " + str(best) + " (" + str(best_kills) + " enemies)"
	game_over_panel.visible = true
  • HUD owns its own nodes, so main.gd asks HUD to show the panel instead of poking at its children. Add the reference to scripts/main.gd:

@onready var hud = $HUD
  • The show call already sits in on_game_over from Step 1, after the record check.
  • BestLabel is the high score label now.

Testing the Record

  • For a quick test, temporarily set fence_durability to 1 in global.gd, then set it back when you are done. One camped enemy ends the run.
  • Play to a game over. The panel shows your survived waves, your kills, and your best, and the Best label jumps if you improved.
  • Let the fence fall while enemies remain. The panel shows, and no wave summary follows.
  • Close the game completely and reopen it, then play to a game over. The panel shows your saved best.
  • Play again and beat the record. The panel shows the new best, and it survives a reopen.
  • Play again and lose early. The panel shows the lower wave, and the best stays put.
  • Play again, tie the record, and get more kills. The best kills update on the panel.
  • Delete user://highscore.json, then reopen the game and play to a game over. The panel reads zero, and nothing breaks.
  • After game over, close and reopen the game for a fresh run.
💡 If the high score will not track:
  • Best never changes: on_game_over is never called. Check the enemy camp block calls it.
  • Best shows zero after reopen: the file never saved, or load never ran. Check save_high_score at game over and load_high_score in _ready.
  • Game over fires twice: the fence guard is missing. Check the fence_durability > 0 check.
  • Panel never shows: show_game_over is never called, or the panel path is wrong. Check main.gd's hud reference.
  • Old best comes back after beating it: save_high_score is not called when the score improves. Check on_game_over.
  • Panel shows the wrong wave: score is waves survived, so current_wave, not current_wave + 1. Check on_game_over.
  • Kills never count: kills += 1 is missing from the take_damage kill branch. Check enemy.gd.
  • Tiebreaker ignored: best_kills never updates on a tied score. Check the elif branch.
  • Game keeps playing behind the panel: paused = true is missing from on_game_over. Check the handler.
  • Best shows on the HUD during play: the old HighScoreLabel is still there. Remove the label and its _process line. The panel's BestLabel is the only best display.
  • Summary shows after game over: the fence condition is missing from the wave-clear check. Check wave_manager.gd _process.
  • Loaded run starts dead: the save was made after game over, when the fence was already zero. Save before the final wave, not after.
