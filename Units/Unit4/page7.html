Section 7: Click-to-Place & Validation

Place towers with mouse clicks and prevent invalid placements.

Section Progress: 0%
What is a class name?

A class name turns your script into a type Godot knows by name. Without one, placement_zone.gd is just a file attached to a node, and other scripts can only describe it as an Area3D. With class_name PlacementZone at the top, PlacementZone becomes a type like Area3D or Node3D, and any script can use it in a variable declaration.

So far you have typed variables as built-in classes: Node3D for towers, Area3D for zones. Those types know about positions, but they do not know about your variables, like occupied. Giving your script a class name puts your type into the same system. Now placement.gd can say hovered_zone is a PlacementZone, and Godot checks every .occupied access properly instead of warning that the access might not be safe.

1

One New Variable

  • Open scripts/placement_zone.gd from Section 6
  • Add one variable at the top of the script, and give the script a class name:
extends Area3D
class_name PlacementZone

var occupied = false
  • Every zone starts unoccupied, a zone becomes occupied when a tower is placed on it.
  • The zone owns its own state. Nothing else has to remember which zones are taken.
  • Finally, tell placement.gd the zone's real type. In scripts/placement.gd, change the hovered_zone declaration:
var hovered_zone: PlacementZone
  • Area3D knows about positions, but it does not know about occupied. Typing the variable as PlacementZone means every .occupied access is checked properly instead of raising an unsafe access warning.

2

Catching the Mouse Click

  • Open scripts/placement.gd from Section 6
  • Add an _unhandled_input function:
func _unhandled_input(event):
	if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
		try_place()
  • _unhandled_input runs for input nothing else has claimed. There is no UI yet, so clicks arrive here.
  • The checks mean left mouse button, pressed down. Without the pressed check, the function would also run when the button is released.
  • try_place does not exist yet, but you could clear the error by making it and passing it until we build it.
Figure 7.2: Click listener in placement.gd
3

From Preview to Real Tower

  • Add try_place to scripts/placement.gd:
func try_place():
	if hovered_zone == null:
		return
	var tower = tower_scene.instantiate()
	add_child(tower)
	tower.global_position = hovered_zone.global_position
	hovered_zone.occupied = true
	preview.visible = false
	hovered_zone = null
  • The null check is a guard. If the player clicks empty ground, there is no hovered zone, so the function stops.
  • add_child comes before setting global_position, so the tower lands in the right spot.
  • The zone is marked occupied, the preview hides, and hovered_zone clears. Moving back onto the zone starts fresh.
  • To test, press F6, hover a zone, and click. A real tower should appear where the ghost was.
Figure 7.3: Tower placed on a zone
4

One Gate for Every Rule

  • Placing already works, but an occupied zone still accepts another tower. We need a second guard to try_place:
func try_place():
	if hovered_zone == null:
		return
	if hovered_zone.occupied:
		return
	var tower = tower_scene.instantiate()
	add_child(tower)
	tower.global_position = hovered_zone.global_position
	hovered_zone.occupied = true
	preview.visible = false
	hovered_zone = null
  • Every placement rule is a guard at the top of this one function. A placement that fails any guard stops before anything is created.
  • Keeping all the rules in one place matters later. When a new rule arrives, it joins these guards instead of hiding somewhere else in the code.
  • We also need to stop the preview from showing on a zone that is already taken. Add the same check to the top of _on_zone_hovered:
func _on_zone_hovered(zone):
	if zone.occupied:
		return
	hovered_zone = zone
	preview.global_position = zone.global_position
	preview.visible = true
Figure 7.4: Validation guards in try_place
5

Test Placement

  • Press F6
  • Hover a zone and click. A tower appears.
  • Hover the same zone again. No ghost appears, and clicking does nothing.
  • Click empty ground. Nothing happens.
  • Place a tower on every zone. Each zone accepts exactly one.
💡 If clicking does nothing:
  • Nothing happens on any click: check that _unhandled_input is in placement.gd and that the Placement node is in the main scene.
  • Not sure the click is reaching the script: add a temporary print("Clicked") at the top of try_place and watch the Output panel.
  • Tower appears in the wrong place: make sure you set global_position after add_child.
  • One zone accepts many towers: occupied is never set to true, or the occupied guard is missing from try_place.
  • Ghost still shows on a taken zone: the occupied check at the top of _on_zone_hovered is missing.
  • Click places a tower with no zone hovered: the hovered_zone null check is missing from try_place.
  • Error about invalid assignment of occupied: the variable is missing from placement_zone.gd, or it landed inside a function instead of at the top of the script.
