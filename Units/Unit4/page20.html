Section 20: Upgrades and Selling

Upgrade towers and sell them back for gold

Section Progress: 0%
1

Clicking Towers

  • Upgrading needs a target, and the target is the tower under the mouse. Add an Area3D named "ClickArea" to each tower scene, and give it a CollisionShape3D covering the tower.
  • Add a signal and a click handler to scripts/tower.gd:

signal tower_clicked(tower)

func _on_click_area_input_event(camera, event, position, normal, shape_idx):
	if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
		tower_clicked.emit(self)
  • Connect ClickArea's input_event signal to the handler, the same way you connected zone signals in Section 6.
  • The preview ghost is a tower scene too, so it has a ClickArea as well. A ghost should not be clickable, or it steals the mouse from the zone it sits on. Add two lines to make_ghost in scripts/placement.gd, the Section 6 function that builds the preview:

func make_ghost(node):
	if node is MeshInstance3D:
		var ghost_material = StandardMaterial3D.new()
		ghost_material.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
		ghost_material.albedo_color.a = 0.5
		node.material_override = ghost_material
	if node is CollisionObject3D:
		node.input_ray_pickable = false
	for child in node.get_children():
		make_ghost(child)
  • input_ray_pickable is the switch for mouse picking. False means the mouse ray passes through the ghost and hits the zone underneath.
  • The function already walks the whole tower, so the ClickArea is the only pickable part it finds. A second tower type later needs no new code.
  • We want the ring to show to indicate the tower is selected, but the ring needs its own look. A placed tower's ring uses the scene material, which is opaque, and the ghost's faint material only exists on the preview. Make one shared yellow material as a resource, then hand it to the code. In the FileSystem dock, create a new resource of type StandardMaterial3D and save it as materials/select_material.tres. In the Inspector, set Transparency to Alpha, Albedo Color to yellow with alpha 0.5, and under Emission, turn on Enabled, set the color to yellow, and set Energy Multiplier to 0.5.
  • Load it in scripts/placement.gd, beside selected_tower:

const SELECT_MATERIAL = preload("res://materials/select_material.tres")
  • preload loads the resource when the script loads, so there is no Inspector step to forget. The path must match the file exactly, or the script fails to load, which is easier to spot than an empty slot.
  • Yellow reads against my grass, change the Albedo and Emission colors in the resource based on your own scene.
  • Emission is the glow. Without it the ring is a flat yellow disc, with it the ring looks lit from inside.
  • The preview ring keeps the ghost material, the selected ring gets the yellow glow, so the two never look alike.
  • Track the selection in scripts/placement.gd:

var selected_tower: Tower = null

func _on_tower_clicked(tower):
	if tower == preview:
		return
	if tower == selected_tower:
		var ring = selected_tower.get_node("RangeRing") as MeshInstance3D
		ring.visible = false
		selected_tower = null
		print("Deselected")
		return
	if selected_tower != null and is_instance_valid(selected_tower):
		var old_ring = selected_tower.get_node("RangeRing") as MeshInstance3D
		old_ring.visible = false
	selected_tower = tower
	var new_ring = selected_tower.get_node("RangeRing") as MeshInstance3D
	new_ring.material_override = SELECT_MATERIAL
	new_ring.visible = true
	new_ring.scale = Vector3(selected_tower.attack_range, 1, selected_tower.attack_range)
	print("Selected ", tower.name, " level ", tower.level)
  • The ghost is a Tower too, so ignore it. Selecting the ghost would upgrade a preview, not a real tower.
  • Clicking the selected tower again deselects it. The toggle is the first check after the ghost guard, so a second click hides the ring and clears the selection.
  • Clicking empty ground does not deselect. The click reaches _unhandled_input after the tower's click handler, so an empty-ground check there would clear a selection made a moment earlier.
  • The scale gets reset on your placed towers. A placed tower is a fresh instance, so its ring is still at the scene default size. I scale it to attack_range here, but you might want to adjust it based on your own scene.
  • The validity check is needed after a load, since loading frees every placed tower. A freed reference would crash the hide line.
  • The prints back up the ring in the Output panel. Level comes from Step 2, so it reads 1 until a tower upgrades.
  • Connect the signal when a tower is placed. In try_place, cast the new tower and connect, right after add_child:

	var tower = tower_scenes[selected_index].instantiate() as Tower
	tower.tower_clicked.connect(_on_tower_clicked)
  • Connect in load_towers too, after add_child in Section 18's rebuild loop, or loaded towers cannot be selected. Set selected_tower = null in load_towers before the rebuild loop, since every placed tower is freed.
  • Clicking a placed tower selects it instead of placing a new one. The tower's ClickArea takes the click, so the zone underneath never hovers.

Stronger, Pricier Each Time

  • Upgrades need a badge, so the player can see a tower's level. Add a Label3D named "LevelLabel" to each tower scene, above the tower, Visible off.
  • Center the label on the y-axis, and place it where it makes sense for your scene.
  • If you don't center on the y-axis, the label will swing around with the tower as it turns.
  • In the Inspector, set Billboard to Enabled, so the badge faces the camera on its own. Billboard is off by default, and without it the label sits flat like any 3D object, which is why a tilted top-down camera reads it edge-on.
  • If the badge hides inside the model, raise it above the tower's top, or turn on No Depth Test in the inspector so it draws over the tower. Do not pull it back off the axis, that is what swings it around when the tower turns.
  • The text is white by default, edit the color and font as you would any other 2D label.
  • Track level and spending in scripts/tower.gd:

var level = 1
var spent = 0
@export var max_level = 5
  • Add one line to _ready in tower.gd, beside the timer setup, so spending starts at the purchase price:

	spent = cost
  • Add apply_upgrade and upgrade to scripts/tower.gd. Each upgrade multiplies damage by 1.5 and divides cooldown by 1.5, and costs 75 percent of the base cost times the current level:

func apply_upgrade():
	attack_damage = roundi(attack_damage * 1.5)
	cooldown_time /= 1.5
	$CooldownTimer.wait_time = cooldown_time
	level += 1
	$LevelLabel.text = "+" + str(level)
	$LevelLabel.visible = true

func upgrade():
	if level >= max_level:
		return false
	var upgrade_cost = roundi(cost * 0.75 * level)
	if Global.gold < upgrade_cost:
		return false
	Global.gold -= upgrade_cost
	spent += upgrade_cost
	apply_upgrade()
	return true
  • Damage and fire rate scale, range stays, so the ring on a selected tower never changes size when it levels up.
  • The cost ramps with the level. The second level costs 75 percent of the base cost, the third costs 150 percent, and the fifth costs 300 percent.
  • The badge lives in apply_upgrade, not upgrade, so a loaded tower gets its badge too, without paying gold.
  • max_level is an export so you can change the value in the inspector. I am using 5 for mine, but you can choose your own.
  • Returning true or false lets the caller report what happened, instead of the tower printing for itself.
  • A saved tower must come back at its level. Add level and spent to get_tower_data in scripts/placement.gd, the Section 18 function that lists placed towers:

func get_tower_data():
	var data = []
	for entry in placed_towers:
		var pos = entry["node"].global_position
		data.append({"index": entry["index"], "position": [pos.x, pos.y, pos.z], "level": entry["node"].level, "spent": entry["node"].spent})
	return data
  • Restore them in load_towers, right after add_child in the rebuild loop, so _ready has already run. Add the as Tower cast to the instantiate line, the same as try_place, or the calls below it warn:

		var tower = tower_scenes[entry["index"]].instantiate() as Tower
		add_child(tower)
		tower.spent = entry["spent"]
		for i in range(entry["level"] - 1):
			tower.apply_upgrade()
  • Re-applying the upgrades rebuilds the stats and the badge from the saved level, and spent gives more value based on upgrades. A loaded level 3 tower sells for base cost plus both upgrades, not base cost alone.
  • Add the caller to scripts/placement.gd:

func upgrade_selected():
	if selected_tower == null or not is_instance_valid(selected_tower):
		return
	if selected_tower.upgrade():
		print("Upgraded to level 2")
	else:
		print("Cannot upgrade")
  • The validity check guards the case where the selected tower was freed, since a freed reference would crash the call.
  • Add an input action called "upgrade_tower" on key U, and call upgrade_selected from _unhandled_input in scripts/placement.gd, beside the selection keys:

	if event.is_action_pressed("upgrade_tower"):
		upgrade_selected()
  • Add a Button named "UpgradeButton" to the HUD, and connect its pressed signal to a handler in scripts/hud.gd:

func _on_upgrade_button_pressed():
	placement.upgrade_selected()
  • The button and the U key call the same function. If you choose, you don't need to implement both.

Seventy Percent Back

  • Add sell_selected to scripts/placement.gd:

func sell_selected():
	if selected_tower == null or not is_instance_valid(selected_tower):
		return
	var refund = roundi(selected_tower.spent * 0.7)
	Global.gold += refund
	for entry in placed_towers:
		if entry["node"] == selected_tower:
			placed_towers.erase(entry)
			break
	for node in get_tree().get_nodes_in_group("placement_zones"):
		var zone = node as PlacementZone
		if zone.global_position.distance_to(selected_tower.global_position) < 0.01:
			zone.occupied = false
	selected_tower.queue_free()
	selected_tower = null
	print("Sold for ", refund, " gold")
  • The refund is 70 percent of everything spent on that tower, base cost plus upgrade, so an upgraded tower refunds more.
  • Erasing from placed_towers is important to include. Without it, a later load would resurrect the sold tower, and the refund would be free money.
  • The zone match is the Section 18 trick again, closeness instead of equality, so the zone frees for the next tower.
  • Freeing the zone before queue_free matters, since the position is read while the tower still exists.
  • Add an input action called "sell_tower" on key S, and call sell_selected from _unhandled_input in scripts/placement.gd, beside the upgrade key:

	if event.is_action_pressed("sell_tower"):
		sell_selected()
  • Add a Button named "SellButton" to the HUD, and connect its pressed signal to a handler in scripts/hud.gd:

func _on_sell_button_pressed():
	placement.sell_selected()

Testing the Economy's Second Half

  • Hover a zone to place. The ghost sits steady, with no flicker, and the zone takes the click.
  • Place a tower, then click it. Its range ring shows in glowing yellow, and the Output panel prints its name and level.
  • Click a second tower. The ring moves to the new tower, and the first tower's ring hides.
  • Click the selected tower again. The ring hides, and the Output panel prints the deselect.
  • Press U. Gold drops by 75 percent of the cost, the tower hits harder and fires faster, and a +2 badge appears above it.
  • Press U again. Gold drops by 150 percent of the cost, and the badge reads +3.
  • Press U until the tower reaches level 5. The next press does nothing, and the Output panel reports it cannot upgrade.
  • Save with a level 3 tower, then load. The tower comes back level 3, with its badge, and sells for the right refund.
  • Press S. Gold jumps by 70 percent of everything spent, base cost plus upgrades, the tower vanishes, and the zone takes a new tower.
  • Save after selling, place a tower, load. The sold tower stays gone, and gold matches the save.
  • Click the ghost preview. No selection prints, since the ghost is ignored.
  • Load a save, then click a rebuilt tower. It selects, upgrades, and sells like any other.
💡 If upgrading will not work:
  • Ghost flickers while hovering a zone: its ClickArea is still pickable and steals the mouse from the zone. Check the input_ray_pickable line in make_ghost.
  • No ring on the selected tower: the ring lines are missing from _on_tower_clicked, or RangeRing is missing from the tower scene.
  • Ring stays on two towers: the old-ring hide lines are missing from _on_tower_clicked. Check the selected_tower block at the top.
  • Clicking the selected tower does nothing: the toggle lines are missing from _on_tower_clicked. Check the tower == selected_tower block at the top.
  • Ring shows opaque instead of glowing yellow: the material_override line is missing from _on_tower_clicked.
  • Script errors on load: the preload path is wrong. Check that the file is named select_material.tres and sits in the materials folder.
  • Click does nothing: the ClickArea shape is missing, or its input_event signal is not connected. Check the tower scene and the connections.
  • Click selects nothing: the tower_clicked connect is missing from try_place or load_towers. Check both.
  • Upgrade does nothing: no tower is selected, so click one first. Check the selection print.
  • Ghost upgrades: the preview guard is missing from _on_tower_clicked. Check the tower == preview line.
  • Damage rises but fire rate stays: the timer wait_time line is missing from apply_upgrade. Check $CooldownTimer.
  • Loaded tower loses its level: get_tower_data is missing level and spent, or load_towers never restores them.
  • Badge never appears: the LevelLabel node is missing from the tower scene, or the badge lines are missing from apply_upgrade.
  • Sold tower returns after load: placed_towers.erase is missing from sell_selected. Check the erase loop.
  • Zone stays blocked after sell: the zone match failed. Check the distance check.
  • Refund is wrong: spent never tracked the purchase. Check the spent = cost line in _ready.
