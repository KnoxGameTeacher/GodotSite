Section 4: Creating a Test Level with TileMapLayer

Create a new test scene, set up TileMapLayer with the Kenney tilesheet, and paint your first visual room.

Section Progress: 0%
1

Creating a New Scene

  • Go to Scene → New Scene or press Ctrl + N
  • Click "Other Node" and select a plain "Node2D" as the root
  • Click "Create"
  • Press Ctrl + S to save the scene
  • Name it "TestLevel.tscn"
  • Save it in your project folder (root directory is fine)
💡 Pro Tip: Creating separate test levels keeps your main game organized. You can always add this to your main scene later!
Figure 4.1: Creating a new Node2D scene and saving as TestLevel.tscn
2

Locating the Tilesheet

  • Navigate to your extracted Scribble Dungeons folder
  • Look for a file named "tilesheet.png" (the main tilesheet image)
  • The tiles are designed at 64x64 pixels per tile
  • This tilesheet includes floor tiles, wall tiles, and doorways

Adding to Your Godot Project

  • In your Godot project's FileSystem dock, locate the assets/ folder
  • If you don't have an assets/ folder, right-click and select "Create Folder"
  • Create a new folder inside assets/ called "tiles"
  • Drag and drop the tilesheet.png file into assets/tiles/
💡 Pro Tip: The Scribble Dungeons pack uses a CC0 license, meaning you can use these tiles freely in any project, even commercial games!
Figure 4.2: The Scribble Dungeons tilesheet added to assets/tiles/
3

🏗️ Adding the TileMapLayer

  • With TestLevel.tscn open, select the root Node2D
  • Click the "+" (Add Child Node) icon
  • Search for and select "TileMapLayer"
  • Click "Create"
  • Right-click the new TileMapLayer node and select "Rename"
  • Rename it to "Background"

What is TileMapLayer?

  • Introduced in Godot 4.3+, replaces the older TileMap node
  • Efficiently renders large numbers of tiles
  • Perfect for creating dungeon rooms and maze levels
  • Includes powerful painting and selection tools
⚠️ Note: If you're using Godot 4.2 or earlier, look for "TileMap" instead of TileMapLayer. The functionality is very similar!
Figure 4.3: Creating a TileMapLayer node and renaming it to "Background"
4

Setting Up the TileSet Resource

  • Select the "Background" (TileMapLayer) node
  • In the Inspector, find the "TileSet" property
  • Click the dropdown and select "New TileSet"
  • Click the "TileSet" property to open the TileSet panel at the bottom

📐 Creating the Atlas from Your Tilesheet

  • In the TileSet panel (bottom of the screen), click "Add Atlas"
  • Locate your tilesheet.png in the FileSystem
  • Drag it into the Atlas area
  • Set the "Tile Size" to "64" x "64"
  • Click "OK" to create the atlas
  • Godot will automatically slice the tilesheet into individual 64x64 tiles
  • You should now see all your tiles (floors, walls, doorways) in the TileSet panel!
💡 Pro Tip: If your tilesheet has spacing around tiles, adjust the "Separation" and "Margin" settings in the Atlas properties!
Figure 4.4: TileSet panel showing the 64x64 atlas sliced from tilesheet.png
5

Selecting and Painting Tiles

  • Make sure the "Background" (TileMapLayer) node is selected
  • Open the TileSet panel at the bottom (if not already open)
  • Click on a floor tile in the left panel to select it (look for stone or cobblestone)
  • Your cursor will change to a paintbrush icon
  • Click in the viewport to paint the selected tile!

🏰 Build a Simple Room

  • Use floor tiles to paint a 10x10 square room
  • Select wall tiles from the TileSet panel
  • Paint walls around the outer edges of your room
  • Select a doorway tile from the tilesheet
  • Add doorways on one or more walls
  • Add decorative tiles like puddles, cracks, or torches

🛠️ Essential Painting Tools

  • Paint (Pencil): D key - Click to paint single tiles
  • Fill (Bucket): F key - Click to fill an area with the selected tile
  • Eraser: E key - Click to remove tiles
  • Selection (Rectangle): S key - Drag to select multiple tiles
  • Zoom: Ctrl + Mouse Wheel
  • Pan View: Middle Mouse Button or Space + Drag
💡 Pro Tip: Use the Fill tool to quickly cover large floor areas, then use the Pencil tool to add details!
Figure 4.5: A simple room painted with floor tiles, walls, and doorways
6

🎮 Adding the Player to Your Test Level

  • In the FileSystem dock, find your player.tscn file
  • Click and drag player.tscn into the viewport
  • Position the player in your room (e.g., near the center or by a doorway)
  • Use the Move tool (Q key) to adjust the player's position

Testing Your Room

  • Press F5 (or click the Play button in the top-right)
  • Your player should appear in the room you painted
  • Use WASD or Arrow Keys to move the player around
  • The player can move freely on the floor tiles
  • Note: Walls are visual only right now - the player can walk through them
  • Press F8 to stop the game
🎯 What You've Accomplished:
  • ✅ Created a new TestLevel.tscn scene
  • ✅ Added and configured a TileMapLayer with the Kenney tilesheet
  • ✅ Painted a visual room with floors, walls, and doorways
  • ✅ Added your player character to the level
  • ✅ Tested player movement in your custom room
Note: Since we haven't added collision to tiles yet, the player can currently walk through walls. In a future lesson, you'll learn how to add collision shapes to tiles to create proper boundaries!
