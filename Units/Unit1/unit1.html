📥 Download Instructions

Godot is completely free and open-source. Follow these steps to get the latest version:

  • Visit the official Godot website: https://godotengine.org
  • Click the "Download" button (it will auto-detect your OS)
  • Choose the standard version (not the .NET version unless you need C#)
  • Select your operating system: Windows, macOS, or Linux
  • Download the 64-bit version for best performance
💡 Pro Tip: Download the "standard" version (not .NET) unless you specifically need C# support. GDScript is easier for beginners!

🖥️ Installation Steps

  • Windows: Run the .exe installer or use the portable ZIP version
  • macOS: Drag Godot.app to your Applications folder
  • Linux: Extract the .tar.gz archive and run the executable
  • Launch Godot after installation completes

🎯 Setting Up a New Project

When you first launch Godot, you'll see the Project Manager. Here's how to create your first project:

  • Click the "New Project" button on the right side
  • Choose a name for your project (e.g., "My First Game")
  • Select a location on your computer to save the project
  • Leave "Renderer" as "Forward+" (best for modern computers)
  • Click "Create & Edit" to open your new project
⚠️ Important: Avoid using spaces or special characters in your project path. Use underscores instead of spaces.

🎨 Understanding Project Structure

Godot creates a project.godot file and a default scene. Your project folder will contain:

  • project.godot - Main project configuration file
  • default_env.tres - Default environment settings
  • icon.svg - Default project icon
  • Subfolders for your scenes, scripts, and assets

🔧 Understanding the Editor Layout

Godot's interface is divided into several key areas:

  • Viewport (Center): The main canvas where you design your game
  • Scene Dock (Left): Shows all nodes in your current scene
  • FileSystem Dock (Bottom Left): Browse your project files
  • Inspector (Right): Adjust properties of selected nodes
  • Bottom Panel: Debug console, animation editor, and more
  • Toolbar (Top): Play/stop buttons, scene management
💡 Pro Tip: You can drag and rearrange any dock to customize your workspace. Reset via Editor → Editor Settings → Interface → Restart to Default Layout.

⌨️ Essential Keyboard Shortcuts

  • F5 - Run the current scene
  • F8 - Stop running the game
  • Ctrl + S - Save current scene
  • Ctrl + Shift + S - Save all scenes
  • Ctrl + Z - Undo
  • Shift + Ctrl + Z - Redo

🖼️ Adding Visual Elements

Let's add a character sprite to your scene:

  • Right-click in the Scene dock and select "Add Child Node"
  • Search for and select "Sprite2D" node
  • Click "Create" to add it to your scene
  • With the Sprite2D selected, look at the Inspector to the right
  • Click the "Texture" property dropdown, then "Load"
  • Navigate to the Godot icon (icon.svg) in your project folder
  • Click "Open" to assign the texture
  • Scale the sprite by adjusting the "Scale" property in Inspector

🎮 Running Your First Game

  • Click the "Play Current Scene" button (or press F5)
  • You should see a window open with your sprite visible!
  • Press F8 or close the window to stop the game
  • Try selecting the sprite and moving it around in the viewport
  • Save your scene (Ctrl+S) and name it "MainScene.tscn"
🎉 Congratulations! You've just created and run your first Godot project. In the next unit, you'll learn how to make it move!
