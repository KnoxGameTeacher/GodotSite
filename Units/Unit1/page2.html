Section 2: Creating A-Maze-Ball Project

Set up a new 3D project called "A-Maze-Ball" with the Forward+ renderer and configure project settings.

Section Progress: 0%
1

Launching the Project Manager

When you open Godot, you'll see the Project Manager window. This is where you can browse existing projects or create new ones.

  • If Godot isn't already open, launch it from your desktop or applications folder
  • In the Project Manager, click the "+New" button on the right side
  • A dialog box will appear asking for project details
  • Click "Browse" to choose where to save your project
  • Create a new folder called "GodotProjects" on your computer (or use an existing folder)
  • Inside that folder, create a subfolder named "A-Maze-Ball"
💡 Pro Tip: Keep all your Godot projects organized in one parent folder (like "GodotProjects") so they're easy to find later!
2

⚙️ Project Configuration

Now we'll set up the basic project information:

  • Project Name: Enter "A-Maze-Ball" (exactly as shown, with hyphens)
  • Project Path: Should show the folder you created (e.g., /Users/YourName/GodotProjects/A-Maze-Ball)
  • Renderer: Select "Forward+" from the dropdown menu
  • Create Folder: Keep this checked (it will create the default project structure)
⚠️ Important: The Forward+ renderer is recommended for modern 3D games. It provides better lighting and visual effects compared to the Compatibility renderer.

🎮 What is Forward+?

  • Supports advanced lighting effects like global illumination
  • Better performance for 3D games with many light sources
  • Recommended for desktop and console games
  • Requires a graphics card that supports Vulkan or Direct3D 12
  • This is more than we need for our simple 2D game, but is the current standard.
3

✨ Creating Your First Project

With all settings configured, it's time to create the project:

  • Double-check that the Project Name is "A-Maze-Ball"
  • Confirm the Renderer is set to "Forward+"
  • Click the "Create" button
  • Godot will now create your project folder and open the editor
  • You'll see the Godot editor with a default empty 3D scene
💡 Pro Tip: The first time you open a new project, Godot creates several default files. These are important so don't delete them!
4

📁 Understanding Your Project Files

Take a moment to explore what Godot created for you:

  • FileSystem Dock (bottom left): Shows all files in your project
  • icon.svg: Default project icon (you would normally replace this)

🎯 What's Next?

Now that your project is set up, you're ready to start building A-Maze-Ball! In the next sections you'll learn how to:

  • Create a 2D maze environment
  • Add a simple ball character
  • Write GDScript code for movement
🎉 Congratulations! You've successfully created your first Godot 3D project. Save your work and move to the next section when you're ready!
