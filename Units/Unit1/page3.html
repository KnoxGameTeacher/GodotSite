Section 3: Creating the Player (CharacterBody2D)

Set up the player character using CharacterBody2D, add the Scribble Dungeons assets, and script top-down movement.

Section Progress: 0%
1

Downloading the Asset Pack

The Scribble Dungeons pack by Kenney provides beautiful hand-drawn style assets perfect for our maze game.

  • Visit https://kenney.nl/assets/scribble-dungeons
  • Click the download button (it's free!)
  • Extract the downloaded ZIP file
  • Navigate the folders to the "PNG / Default 64px / Characters" folder inside the extracted files

Adding Assets to Your Project

  • Back in Godot, In your project's FileSystem dock, right-click and select "Create Folder"
  • Name the folder assets
  • Inside assets, create another folder called player
  • Drag and drop the circle character textures from the extracted folder into assets/player/
💡 Pro Tip: Kenney’s assets use the CC0 license, meaning you can use them for free, even in commercial games!
Figure 3.1: Dragging circle character sprites into the assets/player folder
2

🏗️ Setting Up the Player Scene

We'll create a new scene for the player that will be reused throughout the game.

  • Go to Scene → New Scene or press Ctrl + N
  • Click the "Other Node" button
  • Search for and select "CharacterBody2D"
  • Click "Create"
  • Rename the node to "Player" (right-click the node and select Rename)
⚠️ Important: CharacterBody2D is the standard node for player-controlled characters. It handles movement, collision, and physics automatically!

What is CharacterBody2D?

  • Designed for player-controlled movement
  • Handles collisions and slopes for you
  • Includes built-in methods like move_and_slide()
  • Perfect for top-down and platformer games
Figure 3.2: Creating a new CharacterBody2D node as the root of the player scene
3

Adding Visual and Collision Components

With the Player node selected, add these child nodes:

  • Click the "+" icon (Add Child Node) next to the Player node
  • Search for and add "Sprite2D"
  • With Sprite2D selected, look at the Inspector
  • Find the "Texture" property and click the dropdown
  • Select "Load" and navigate to your assets/player/ folder
  • Choose the circle character sprite you want (e.g., blue_character.png)
  • Click "Open" to apply the texture

Adding Collision Detection

  • Again, click the "+" icon next to the Player node
  • Search for and add "CollisionShape2D"
  • With CollisionShape2D selected, go to the Inspector
  • Click the "Shape" dropdown and select "Circle Shape2D"
  • Click and drag the orange handles to roughly match the size of your character sprite
  • The collision shape should cover the body of the character
💡 Pro Tip: A good collision shape should be slightly smaller than the sprite to avoid getting stuck on walls!
Figure 3.3: Sprite2D with circle texture and CollisionShape2D outline
4

Saving Your Player Scene

Now we'll save this player setup as a reusable scene file.

  • Press Ctrl + S (or Cmd + S on Mac) to save the scene
  • Navigate to your project folder (usually the root or a scenes/ folder)
  • Name the file "player.tscn"
  • Click "Save"
  • You should now see player.tscn in your FileSystem dock
💡 Pro Tip: Saving reusable scenes allows you to place multiple players or use the same player across different levels!
Figure 3.4: Saving the player scene as player.tscn
5

Attaching a GDScript

  • Select the Player node (CharacterBody2D)
  • Click the "📄" icon with a green plus sign with your Character node selected to add a script
  • Name the script "player.gd"
  • Click "Create"
  • The script editor will open with some default code

Writing Top-Down Movement Code

Replace the default code with this complete top-down movement script:


                                
extends CharacterBody2D


@export var SPEED = 300.0
const JUMP_VELOCITY = -400.0


func _physics_process(_delta: float) -> void:
	# Get the input direction and handle the movement/deceleration.
	# As good practice, you should replace UI actions with custom gameplay actions.
	var direction = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
	if direction:
		velocity = direction * SPEED
	else:
		velocity = velocity.move_toward(Vector2.ZERO, SPEED)

	move_and_slide()
💡 Pro Tip: The @export keyword lets you edit the speed value directly in the Inspector without changing code!

🎮 Understanding the Code

  • extends CharacterBody2D - Inherits movement abilities from the node type
  • @export var speed - A variable you can adjust in the Inspector
  • _physics_process - Called every physics frame (good for movement)
  • Input.get_vector() - Detects keyboard/controller input for 8-directional movement
  • move_and_slide() - Moves the character and handles collisions automatically
