Section 5: Adding Collision to Walls

Create a collision-ready wall layer using transparent tiles and configure collision shapes in the TileSet panel.

Section Progress: 0%
1

🎨 Understanding the Blue Boundary

The blue rectangle in your viewport represents the visible game area. We want to fill this entire area with floor tiles.

  • Select the "Background" (TileMapLayer) node
  • In the TileSet panel, select a basic floor tile
  • Switch to the Paint Tool (press D key or click the pencil icon)
  • Draw a rectangle around the area, switch to the Bucket B and fill the area
  • The entire visible game area should now be covered with floor tiles
💡 Pro Tip: The Fill tool is perfect for covering large areas quickly. Just make sure you have the right tile selected!
Figure 5.1: The entire blue boundary filled with basic floor tiles
2

🏗️ Adding a Separate Layer for Walls

Using separate layers keeps your level organized and makes collision management easier.

  • Select the "Background" (TileMapLayer) node
  • Click the "+" (Add Child Node) icon, or Ctrl+A to add a node
  • Search for and select "TileMapLayer"
  • Click "Create"
  • Right-click the new node and rename it to "Walls"
💡 Pro Tip: Using multiple TileMapLayer nodes (Background, Walls, Decorations) makes editing and adjusting each layer much easier!

❓ Why a Separate Walls Layer?

  • Makes it easy to edit walls without affecting the floor
  • Better performance and organization
Figure 5.2: Creating a child TileMapLayer node named "Walls"
3

🖼️ Setting Up the Walls TileSet

  • Select the "Walls" (TileMapLayer) node
  • In the Inspector, find the "TileSet" property
  • Click the dropdown and select "New TileSet"
  • Click the "TileSet" property to open the TileSet panel
  • Click "Add Atlas" and drag your tilesheet.png again
  • Set "Tile Size" to "64" x "64"
  • Click "OK" to create the atlas
💡 Pro Tip: You can reuse the same tilesheet across multiple TileMapLayer nodes. Each layer can have different collision settings!
Figure 5.3: Configuring the Walls layer with the same tilesheet atlas
4

🧱 Painting the Outer Walls

  • Select the "Walls" (TileMapLayer) node
  • In the TileSet panel, select a wall tile with transparent background
  • Paint walls along the outer edge of your room

🔄 Using Tile Rotation

To create a complete wall enclosure, you'll need to rotate wall tiles to face different directions:

  • Select a wall tile in the TileSet panel
  • Before painting, use rotation shortcuts:
  • X key - Rotate 90 degrees Right
  • Z key - Rotate 90 degrees Left
  • You can also click the rotation icons in the top toolbar of the TileSet Panel
Figure 5.4: Walls painted around the room perimeter using tile rotation
5

🛡️ Adding Collision to Tiles

This is the most important step! We'll add collision shapes to each wall tile so the player can't walk through them.

  • With the "Walls" node selected, open the TileSet panel
  • In the Inspector panel, click the "Physics Layers" section
  • Click "Add Physics Layer" and then click "Add Element"
  • On the TileSet panel again, double-click the atlas preview that says "tilesheet.png"
  • Click on Select, click on a wall tile that you used on the room
  • Using the Add Polygon tool, click to add points at the corners of the wall
  • Do the same for any other wall tiles used in this scene
⚠️ Important: Make sure collision polygons cover the entire solid area of each wall tile. If the polygon is too small, the player might clip through corners!
Figure 5.5: Adding a collision polygon to a wall tile in the TileSet panel
6

💾 Save Your Work

  • Press Ctrl + S to save your TestLevel.tscn
  • Make sure both Background and Walls layers are saved
  • The TileSet collision data saves automatically with the scene

🎮 Testing Your Collision Walls

  • Press F5 to run the game
  • Try to move your player through the walls
  • You should now bump into walls instead of walking through them!
  • Test all four walls and corners

🐛 Troubleshooting Common Issues

  • Player walks through walls: Forgot to add collision polygon to the wall tile
  • Player gets stuck on walls: Collision polygon extends beyond the visual wall
  • Some walls work, others don't: Not all wall tiles have collision polygons added
🎉 Congratulations! Your A-Maze-Ball game now has proper collision! The player can explore the room but isn't much of a "maze". We'll fix that next with some level design!
