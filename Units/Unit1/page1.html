Section 1: Getting Started

Download, install, and launch Godot for the first time.

Section Progress: 0%
1

Accessing Godot Engine

Godot is completely free and open-source. Follow these steps to get the latest version:

  • Open your web browser (Chrome, Firefox, or Edge)
  • Navigate to https://godotengine.org
  • Look for the "Download" button in the top menu
  • The site will automatically detect your operating system
💡 Pro Tip: Bookmark the Godot website for quick access to documentation and tutorials!
2

Version Selection Guide

Choosing the right version is important for your learning experience:

  • Standard Version (Recommended): Best for beginners, uses GDScript. This is the version we will be using.
  • .NET Version: Only if you already know C# programming
  • Steam Version: Automatic updates, but may have slight delays
⚠️ Important: Always download the latest stable version (not the alpha/beta releases) for class.
3

Installation Instructions by OS

Windows:
  • Run the downloaded .exe installer
  • Follow the installation wizard prompts
  • Choose installation directory (default is fine)
  • Check "Create desktop shortcut" for easy access
macOS:
  • Open the downloaded .dmg file
  • Drag Godot.app to your Applications folder
  • You may need to allow apps from unidentified developers in your Mac settings
