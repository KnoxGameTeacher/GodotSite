Unit 1 Test: A-Maze-Ball Fundamentals

Demonstrate your mastery of Godot basics by polishing your maze game with multiple levels after first checking your game for completion.

30
Required Points
10
Bonus Points

Test Instructions

  • The top sections are all review, walk through each step to make sure you have completed those items and check them off
  • Complete ALL required sections (30 points total)
  • You MUST create Level2.tscn and Level3.tscn with increasing difficulty
  • Bonus challenges are optional (up to 10 extra points)
  • Submit your entire project folder for grading
  • Use the checkboxes below to track your progress
Test Progress: 0%
Section 1: Project Setup & Player Movement (4 points)
1

✅ Verification Checklist

  • Open your project.godot file in a text editor
  • Check that config/name="A-Maze-Ball"
  • Project runs without errors
2

✅ Verification Checklist

  • Open player.tscn
  • Root node is CharacterBody2D named "Player"
  • Has Sprite2D child with texture assigned
  • Has CollisionShape2D child with shape assigned
3

✅ Verification Checklist

  • player.gd script attached to Player node
  • Uses Input.get_vector() for input detection
  • Velocity is set correctly and uses move_and_slide()
  • Player moves smoothly in 4 directions
Section 2: TileMapLayer & Level Design (11 points)
4

✅ Verification Checklist

  • tilesheet.png exists in assets/tiles/ folder
  • TileSet resource created with 64x64 tile size
  • Atlas is properly sliced showing all tiles
  • TileSet saved as .tres file in assets/tiles/ folder
5

✅ Verification Checklist

  • Level1.tscn exists with Node2D root
  • Has "Background" TileMapLayer child
  • Has "Walls" TileMapLayer child
  • Both layers use the saved TileSet resource
6

✅ Verification Checklist

  • Entire blue visible area covered with floor tiles
  • Walls painted around perimeter and interior maze paths
  • All wall tiles have collision polygons added
  • Player cannot walk through walls
7

✅ Verification Checklist

  • Area2D named "Exit" placed at maze exit
  • CollisionShape2D covers the doorway area
  • Script attached with body_entered signal connection
  • Script loads next level or Win.tscn when player touches exit
8

Required: Create Level2.tscn

  • Create a new scene called Level2.tscn
  • Follow the same structure as Level1 (Background + Walls layers)
  • Use the saved TileSet resource
  • Paint a COMPLETE maze layout (not just a copy of Level1)
  • Must have floor tiles, walls with collision, and an exit trigger
⚠️ Requirement: Level2 must be a different maze than Level1, not just a minor variation!
9

Difficulty Progression Criteria

  • Level2 is LARGER than Level1 (more tiles or more complex layout)
  • Level2 has MORE dead ends or branching paths
  • Level2 requires more strategic navigation
  • Consider making passages narrower or adding more turns
10

Required: Create Level3.tscn

  • Create a new scene called Level3.tscn
  • Follow the same structure as previous levels
  • Use the saved TileSet resource
  • Paint a COMPLETE maze layout
  • Must have floor tiles, walls with collision, and an exit trigger
11

Difficulty Progression Criteria

  • Level3 is noticeably more challenging than Level2
  • Difficulty increases: Level1 (easiest) → Level2 (medium) → Level3 (hardest)
  • All three levels are clearly distinct from each other
Section 3: Scene Management & UI (6 points)
12

✅ Verification Checklist

  • Start.tscn exists with Control root node
  • Has Label with game title "A-Maze-Ball"
  • Has "Start Game" button
  • Has "Quit" button
  • Buttons have proper signal connections
13

✅ Verification Checklist

  • Win.tscn exists (can be duplicated from Start.tscn)
  • Label says "You Win!" or similar victory message
  • Has "Play Again" button that loads Level1.tscn
  • Optional: "Quit" or "Main Menu" buttons
14

✅ Verification Checklist

  • Open Project → Project Settings → General
  • Check Application → Run → Main Scene points to "res://Start.tscn"
  • Game launches to Start screen when pressing F5
  • Complete game loop works: Start → Level1 → Win → Play Again
Section 4: Code Quality & Organization (3 points)
15

✅ Verification Checklist

  • Scripts have comments explaining key sections
  • Variable names are meaningful (e.g., "speed" not "s")
  • Functions are properly indented
  • No orphaned or commented-out code
16

✅ Verification Checklist

  • assets/ folder contains tiles/ and player/ subfolders
  • Scene files are in root or a levels/ folder
  • Scripts are in the scripts/ folder

Bonus Challenges (Optional - up to 10 points)
⭐

🏆 Bonus Challenge 1

Enhance the visual appeal of your levels.

  • Added decorative tiles to at least one level (2 points)
  • Change the color settings of the layers so that it is easy to distinguish them (1 point)
💡 Pro Tip: Use a TileMap node to place decorative elements on an extra layer!
⭐

🏆 Bonus Challenge 2

Replace the Start button with a level select menu.

  • Add buttons for each level (1 point)
  • Players can choose which level to play (Level1, Level2, Level3) (1 point)
  • Win scene returns to level select instead of restarting Level1 (1 point)
⭐

🏆 Bonus Challenge 3

Add collectible items to one or more levels.

  • Create a collectible item scene with Area2D and Sprite2D (2 points)
  • Collectibles disappear when collected and increment a UI counter (2 points)
