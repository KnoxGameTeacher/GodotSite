Section 5: Game Over & Restart

Create a Game Over screen with restart functionality.

Section Progress: 0%
1

💀 Game Over Screen

  • Create a new scene with Control root
  • Add a Label with text "GAME OVER"
  • Add a Button with text "Play Again"
  • Add a Button with text "Quit" (optional)
  • Save as "GameOver.tscn"
Figure 5.1: Game Over scene with Play Again button
2

🔄 Restart Script

Attach this script to the GameOver node:

extends Control

func _ready():
    $PlayAgainButton.pressed.connect(_on_play_again_pressed)
    $QuitButton.pressed.connect(_on_quit_pressed)

func _on_play_again_pressed():
    get_tree().change_scene_to_file("res://Game.tscn")

func _on_quit_pressed():
    get_tree().quit()
💡 Pro Tip: Resetting the game loads a fresh copy of Game.tscn, resetting score and all game objects!
