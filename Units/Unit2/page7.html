Creating a Reusable Exit

The Exit scene will be placed at the end of each level. When the player touches it, the game loads the next level.

  • Press Ctrl + N to create a new scene
  • Add an Area2D as the root node
  • Rename it to "Exit"
  • Add a CollisionShape2D child
  • Set the shape to RectangleShape2D covering the exit area
  • Do not add a Sprite2D - this exit is invisible
  • Save the scene as "exit.tscn"
💡 Pro Tip: Making the exit invisible allows you to place it anywhere without visual clutter. The player triggers it by walking through the area.
2

Exit Script

This script detects when the player touches the exit and triggers the next level.

extends Area2D

func _ready():
    body_entered.connect(_on_body_entered)

func _on_body_entered(body):
    if body.name == "Player":
        # Find the Game node
        var game = get_tree().current_scene
        if game and game.has_method("load_next_level"):
            game.load_next_level()
            queue_free()  # Remove the exit after use
💡 New Concept: queue_free() removes the exit node after it's triggered, preventing multiple activations.

Game Level Management

Let's finish the game flow in Game.gd. Add this new function, which advances to the next level:

func load_next_level():
    var next_level = current_level + 1
    load_level(next_level)

Update load_level() so the game is won when there are no more levels — replace the print("Level not found...") line in its else branch with:

    else:
        win_game()

Finally, replace win_game() and game_over() with versions that add the win/lose screens as children of the Game node instead of switching scenes:

func win_game():
    var win_scene = load("res://Scenes/Levels/Win.tscn")
    var win_instance = win_scene.instantiate()
    add_child(win_instance)

func game_over():
    var game_over_scene = load("res://Scenes/Levels/GameOver.tscn")
    var game_over_instance = game_over_scene.instantiate()
    add_child(game_over_instance)
💡 New Concept: Adding the win screen as a child of the Game node keeps the Game (and its score variable) alive. The win screen can then read the score straight from the Game instead of needing it saved somewhere first.
⚠️ Important: The game checks if the next level file exists. If not, it triggers the win screen.

Creating the Win Screen

  • Create a new scene with CanvasLayer as the root node
  • Add a Label with text "You Win!"
  • Add another Label for displaying final score
  • Rename the score Label to "ScoreLabel" (the script below looks for $ScoreLabel)
  • Add a Button with text "Play Again" and rename it "PlayAgainButton"
  • Add a Button with text "Quit" and rename it "QuitButton"
  • Select the "PlayAgainButton" button
  • In the Inspector, click the "Node" tab (next to Inspector)
  • Find the "pressed()" signal and double-click it
  • Connect it to the root CanvasLayer node and click "Connect" (keep the suggested name _on_play_again_pressed)
  • Select the "QuitButton" button and connect its "pressed()" signal the same way (keep _on_quit_button_pressed)
  • Save as "Win.tscn" inside your "Scenes/Levels" folder

Win Scene Script

extends CanvasLayer

@onready var score_label = $ScoreLabel
@onready var play_again_button = $PlayAgainButton
@onready var quit_button = $QuitButton

func _ready():
    # The Game node is still the current scene, so read the score from it directly
    var game = get_tree().current_scene
    score_label.text = "Final Score: " + str(game.score)

func _on_play_again_pressed():
    # Reloading Game.tscn starts everything fresh (score, health, level 1)
    get_tree().change_scene_to_file("res://Game.tscn")

func _on_quit_button_pressed():
    get_tree().quit()
💡 Pro Tip: The Win scene displays the player's final score and offers options to continue playing or return to the main menu.

Creating the Game Over Screen

  • This is as simple as duplicating the Win scene
  • Change the title Label text to "Game Over" or something similar
  • Keep the final score label to show how well the player did
  • Keep the "Play Again" and "Quit" buttons — make sure they are still named "PlayAgainButton" and "QuitButton" (the script below looks for those names)
  • Connect the buttons' "pressed()" signals the same way you did for the Win scene (keep _on_play_again_pressed and _on_quit_button_pressed)
  • Save as "GameOver.tscn" inside your "Scenes/Levels" folder

Creating Level2.tscn

  • Create a new scene with Node2D as the root
  • Name it "Level"
  • Add TileMapLayer nodes for Ground and Platforms
  • Paint a new, more challenging level
  • Place the player, enemies, coins, and an exit

Testing Your Full Game

  • Open Game.tscn
  • Press F5 to run the game
  • Play through Level1
  • Reach the exit to trigger Level2
  • Complete Level2 to reach the Win screen
  • Test what happens when you lose all health

Complete Game Flow

  • Game.tscn → Loads Level1
  • Level1 → Player reaches exit → Loads Level2
  • Final level → Player reaches exit → Win screen appears over the game
  • Win screen → Player clicks "Play Again" → Restarts Game.tscn
  • Game Over screen → Player clicks "Play Again" → Restarts Game.tscn
🎉 Congratulations! You've built a complete platformer with multiple levels, enemies, collectibles, health, score, and a full game loop!
