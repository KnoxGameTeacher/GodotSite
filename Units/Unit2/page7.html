Section 7: Win Condition & Polish

Add a win condition, sound effects, and visual polish to complete your game.

Section Progress: 0%
1

🏆 Victory Screen

  • Duplicate GameOver.tscn and rename to Win.tscn
  • Change the Label text to "YOU WIN!"
  • Change button text to "Play Again"
  • Optionally change colors to celebrate victory
Figure 7.1: Win screen with Play Again button
2

🎯 Win Condition Script

Add to Game.gd:

var win_score = 100
var score = 0

func add_score(amount):
    score += amount
    $CanvasLayer/ScoreLabel.text = "Score: " + str(score)
    
    if score >= win_score:
        get_tree().change_scene_to_file("res://Win.tscn")
Figure 7.2: Script that checks for win condition
3

🎮 Start Menu

  • Create Start.tscn with Control root
  • Add title "Gem Catcher"
  • Add "Start Game" button (loads Game.tscn)
  • Add "Quit" button
  • Set as Main Scene in Project Settings
