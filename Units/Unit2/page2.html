Section 2: Player Scene & Gravity

Set up the player character with gravity, collision, and basic movement using the sprite from your chosen asset pack.

Section Progress: 0%
1

Creating the Player Scene

  • Press Ctrl + N to create a new scene
  • Click "Other Node" and search for CharacterBody2D
  • Click "Create"
  • Right-click the node and select "Rename"
  • Name it "Player"
💡 Note: CharacterBody2D is designed for player-controlled movement and handles physics collisions automatically.
Figure 2.1: Creating a new CharacterBody2D node as the Player root
2

Adding Visuals to the Player

  • Select the Player node
  • Click the "+" (Add Child Node) icon
  • Search for and add a Sprite2D node
  • In the FileSystem dock, navigate to your imported asset pack
  • Look for the Characters or Player folder
  • Find a single sprite frame (not the whole spritesheet yet)
  • Select the Sprite2D node, then in the Inspector click the "Texture" dropdown
  • Select "Load" and choose your character sprite PNG
💡 Pro Tip: Kenney packs often include individual sprite PNG files. For now, pick one static frame. We will add animation later.
Figure 2.2: Adding a Sprite2D child with a character sprite
3

Setting Up Collision Detection

  • Select the Player node
  • Add a child node: CollisionShape2D
  • In the Inspector, click the "Shape" dropdown
  • Select the shape that makes the most sense for your character
  • Use the orange handles to resize the shape around your character
  • The collision shape should roughly match the character's body size
  • Make it slightly smaller than the sprite to avoid getting stuck on walls
⚠️ Important: The collision shape determines how your character interacts with platforms and walls. A properly sized shape is essential for good gameplay feel.
Figure 2.3: Adding a CollisionShape2D around the character sprite
4

Player Script with Gravity

Select the Player node and click the "📄" icon next to Script. Name it "player.gd" and add this code:

extends CharacterBody2D

@export var speed = 300.0
@export var gravity = 980.0

func _physics_process(delta):
    # Apply gravity
    velocity.y += gravity * delta
    
    # Get horizontal input
    var direction = Input.get_axis("ui_left", "ui_right")
    velocity.x = direction * speed
    
    move_and_slide()

Understanding the Code

  • @export var speed - Horizontal movement speed (editable in the Inspector)
  • @export var gravity - Downward force (980 is realistic for platformers)
  • velocity.y += gravity * delta - Increases downward velocity each frame
  • Input.get_axis() - Returns -1 for left, 1 for right, 0 for none
  • move_and_slide() - Moves the character and handles collisions
💡 New Concept: Gravity makes the player fall. Without it, the character would float in the air!
