Section 4: Enemy Movement & Collision

Add moving enemies that patrol back and forth and end the game on contact.

👾 Creating the Enemy

  • Create a new scene with Area2D root
  • Rename to "Enemy"
  • Add a Sprite2D child (use a red square or skull image)
  • Add a CollisionShape2D child with RectangleShape2D
  • Save as "enemy.tscn"
Figure 4.1: Enemy scene with Area2D
2

🚶 Enemy Patrol Script

extends Area2D

@export var speed = 100.0
@export var left_limit = 50
@export var right_limit = 750

var moving_right = true

func _physics_process(delta):
    if moving_right:
        position.x += speed * delta
        if position.x >= right_limit:
            moving_right = false
    else:
        position.x -= speed * delta
        if position.x <= left_limit:
            moving_right = true
💡 New Concept: Patrolling enemies move back and forth between two limits - great for adding challenge!

💀 Enemy Contact Script

Add this to the Enemy script:

signal game_over

func _ready():
    body_entered.connect(_on_body_entered)

func _on_body_entered(body):
    if body.name == "Player":
        game_over.emit()

Then in your Game script:

func _on_enemy_game_over():
    get_tree().change_scene_to_file("res://GameOver.tscn")
