Section 1: Project Setup & Player Movement

Create the "Forage Frenzy" project, download and import Kenney assets, and set up the player character with tilemap-based animation.

Section Progress: 0%
1

Creating the Project

  • Open Godot and click "New Project"
  • Name the project "Forage Frenzy"
  • Choose a location on your computer
  • Select "Forward+" as the renderer
  • Click "Create & Edit"
💡 Pro Tip: "Forage Frenzy" is a collection game where you will gather mushrooms and avoid obstacles in a woodland setting.
Figure 1.1: Creating the Forage Frenzy project
2

Downloading Required Assets

We need two asset packs from Kenney for this game:

  • Map Pack: https://kenney.nl/assets/map-pack
    • Contains ground tiles (grass, dirt, paths)
    • Includes mushrooms and other forageable items
    • Perfect for the woodland foraging theme
  • Sokoban Pack: https://kenney.nl/assets/sokoban
    • Contains a character sprite sheet with animations
    • Includes crates and walls (for future obstacles)
    • The character is what we will use for the player
💡 License Notice: Both asset packs use the Creative Commons CC0 license. You may use them freely in any project, even commercial games.

Download Instructions

  • Click each link above to visit the Kenney website
  • Click the "Download" button for each pack
  • Extract both ZIP files to a location you can find easily
  • Inside the extracted folders, you will find PNG spritesheets and individual sprites
Figure 1.2: Downloading Map Pack and Sokoban assets from Kenney
3

Organizing Your Project Assets

  • In the FileSystem dock, right-click and select "Create Folder"
  • Create a folder named "assets"
  • Inside assets, create subfolders:
    • characters/ - for player and NPC sprites
    • environment/ - for ground tiles and obstacles
    • items/ - for mushrooms and collectibles

Copying the Assets

  • From the Sokoban extracted folder, find the character spritesheet
  • Drag it into the assets/characters/ folder
  • From the Map Pack extracted folder, find the ground tiles
  • Drag ground tile PNG files into assets/environment/
  • Find mushroom and item sprites in the Map Pack and drag into assets/items/
⚠️ Important: Keep your assets organized. A clean project structure will save you hours of searching later.
Figure 1.3: Organized assets in the FileSystem dock
4

Setting Up the Player

  • Press Ctrl + N to create a new scene
  • Add a CharacterBody2D as the root node
  • Rename it to "Player"
  • Add a Sprite2D as a child
  • In the Sprite2D's Texture property, load one of the character sprites from assets/characters/
  • Add a CollisionShape2D as a child
  • Set the CollisionShape2D to a RectangleShape2D roughly matching the character size
  • Save the scene as "player.tscn"
💡 Note: The Sokoban character spritesheet contains multiple frames. For now, we will use a single frame. Animation will be added later.
Figure 1.4: Player scene with CharacterBody2D and Sprite2D
5

Player Movement Script

Attach this script to the Player node:

extends CharacterBody2D

@export var speed = 400.0

func _physics_process(delta):
    var direction = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    velocity = direction * speed
    move_and_slide()
    
    # Keep player within screen boundaries
    position.x = clamp(position.x, 0, get_viewport_rect().size.x)
    position.y = clamp(position.y, 0, get_viewport_rect().size.y)
💡 New Concept: The clamp() function keeps the player from leaving the screen edges.
