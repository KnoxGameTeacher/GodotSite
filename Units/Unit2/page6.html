Section 6: Spawning Gems with Timer

Use Timer nodes to spawn gems at random intervals and positions.

Section Progress: 0%
1

⏰ Setting Up the Spawn Timer

  • Open Game.tscn
  • Add a new child node: Timer
  • Rename it to "SpawnTimer"
  • In the Inspector, set Wait Time to 1.5 seconds
  • Enable Autostart to begin spawning immediately
Figure 6.1: Timer node configured for spawning
2

📦 Spawning Script

Add this to your Game.gd script:

@onready var spawn_timer = $SpawnTimer
var gem_scene = preload("res://gem.tscn")

func _ready():
    spawn_timer.timeout.connect(_on_spawn_timer_timeout)

func _on_spawn_timer_timeout():
    var gem = gem_scene.instantiate()
    gem.position = Vector2(randf_range(50, 750), randf_range(50, 550))
    gem.collected.connect(_on_gem_collected)
    add_child(gem)
💡 New Concepts: preload() loads a scene, instantiate() creates a copy, and randf_range() creates random numbers!
