Section 3: Score System with UI

Create a score counter that updates when gems are collected using signals.

Section Progress: 0%
1

🎮 Setting Up the Game Scene

  • Create a new scene with Node2D root called "Game"
  • Add your player.tscn as a child
  • Add a CanvasLayer node for UI
  • Inside CanvasLayer, add a Label named "ScoreLabel"
  • Position the label in the top-left corner
  • Save as "Game.tscn"
Figure 3.1: Game scene with CanvasLayer and ScoreLabel
2

📊 Score Management Script

Attach this script to the Game node:

extends Node2D

var score = 0

func _ready():
    # Connect gem signal when gems are spawned
    pass

func add_score(amount):
    score += amount
    $CanvasLayer/ScoreLabel.text = "Score: " + str(score)

func _on_gem_collected():
    add_score(10)
💡 New Concept: Signals allow different scenes to communicate. The gem tells the game "I was collected!" and the game adds to the score!
