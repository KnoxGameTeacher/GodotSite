Section 7: Predator AI (Chase)

Create predators that chase the player and deal damage, adding danger and tension to your game world.

Creating a Predator Animal

We'll create a predator scene (wolf, bear, or other hunter) that will chase the player. Like the prey, it will support multiple models.

  • Press Ctrl + N to create a new scene
  • Add a CharacterBody3D as the root node
  • Rename it to "Predator"
  • Save the scene as "predator.tscn"
Setting Up the Node Structure
  • Add a child node: Node3D
  • Rename it to "ModelContainer"
  • Add a CollisionShape3D as a child of Predator
  • Set the shape to CapsuleShape3D
  • Set the height to 1.2 and radius to 0.6
💡 Note: The Predator scene is similar to the Prey scene, but with different behavior (chase instead of flee) and larger collision size.

Getting Predator Models

You'll need predator animal models. Here are some options:

  • Kenney Animal Pack: https://kenney.nl/assets/animal-pack
  • KayKit Animals: https://kaylousberg.com/game-assets
  • Itch.io Free 3D Animals: Search for "animals"
Importing Models
  • Download predator models (.glb or .gltf)
  • Place them in assets/animals/
  • Name them clearly: wolf.glb, bear.glb, etc.
💡 Pro Tip: If you don't have predator models yet, use a red-colored BoxMesh or CapsuleMesh as a placeholder. The behavior will work the same way!

Chase Script with Multiple Models

Add this script to the Predator node:

extends CharacterBody3D

@export var speed = 3.0
@export var detection_range = 10.0
@export var attack_range = 1.5
@export var attack_cooldown = 2.0
@export var damage = 10.0

@export var animal_type: String = "wolf"

@onready var model_container = $ModelContainer

var target: Node3D
var attack_timer = 0.0
var is_chasing = false
var wander_direction: Vector3
var wander_timer = 0.0

func _ready():
    load_model()
    
    target = get_tree().current_scene.get_node("Player")
    if target == null:
        print("⚠️ Predator: No player found!")
    
    randomize_wander()

func load_model():
    for child in model_container.get_children():
        child.queue_free()
    
    var model_path = ""
    match animal_type:
        "wolf":
            model_path = "res://assets/animals/wolf.glb"
        "bear":
            model_path = "res://assets/animals/bear.glb"
        "big_cat":
            model_path = "res://assets/animals/big_cat.glb"
        _:
            model_path = "res://assets/animals/default_predator.glb"
    
    if ResourceLoader.exists(model_path):
        var model = load(model_path).instantiate()
        model_container.add_child(model)
    else:
        print("Model not found: ", model_path)

func _physics_process(delta):
    if target == null:
        return
    
    attack_timer = max(attack_timer - delta, 0)
    
    var distance_to_player = global_position.distance_to(target.global_position)
    
    if distance_to_player < detection_range:
        is_chasing = true
        var direction = (target.global_position - global_position).normalized()
        velocity = direction * speed
        
        if velocity.length() > 0.1:
            var target_rotation = atan2(velocity.x, velocity.z)
            rotation.y = lerp(rotation.y, target_rotation, 0.1)
        
        if distance_to_player < attack_range and attack_timer == 0:
            attack_player()
    else:
        is_chasing = false
        wander(delta)
    
    move_and_slide()

func wander(delta):
    wander_timer += delta
    if wander_timer > 2.0 + randf() * 3.0:
        randomize_wander()
        wander_timer = 0.0
    
    velocity = wander_direction * speed * 0.3

func randomize_wander():
    wander_direction = Vector3(randf_range(-1, 1), 0, randf_range(-1, 1)).normalized()

func attack_player():
    if target.has_method("take_damage"):
        target.take_damage(damage)
    attack_timer = attack_cooldown
    print("Predator attacked!")

Understanding the Code

  • @export var speed - How fast the predator moves
  • detection_range - How far the predator can see the player
  • attack_range - How close the predator must be to attack
  • attack_cooldown - Time between attacks (prevents spam)
  • damage - How much health the player loses per attack
  • attack_timer - Tracks time since last attack
💡 Reminder: has_method() checks if an object has a specific function before calling it. This prevents errors if the target doesn't have the expected function.

Adding Danger to the World

  • Open your Environment.tscn scene
  • In the FileSystem dock, find predator.tscn
  • Drag it into the viewport multiple times
  • For each instance, select it and go to the Inspector
  • Find the animal_type property
  • Choose different predators for each instance
Example Placement
  • Wolf 1: animal_type = "wolf", speed = 4.0, detection_range = 12.0
  • Bear 1: animal_type = "bear", speed = 2.5, detection_range = 8.0, damage = 20
  • Big Cat 1: animal_type = "big_cat", speed = 5.0, detection_range = 15.0
⚠️ Important: Place predators away from the player's starting position! Give the player time to gather food before facing danger.

Making Predators Dangerous

In your Player script, make sure the take_damage() function exists and updates health:

# In player.gd - Add if not already present
func take_damage(amount):
    health -= amount
    health = max(health, 0)
    update_hud()
    
    # Knockback effect (optional)
    var knockback_direction = (global_position - predator.global_position).normalized()
    velocity = knockback_direction * 5.0
    
    if health <= 0:
        game_over()
💡 Pro Tip: Adding a knockback effect when the player is attacked creates a more visceral, responsive feel. The player feels the impact of being hit.

Testing Your Predators

  • Press F5 to run the game
  • Walk toward a predator
  • The predator should chase you
  • If it catches you, it should attack and reduce your health
  • The HUD health bar should update
  • If you run away far enough, the predator should give up and wander

Troubleshooting Common Issues

  • Predator doesn't chase: Check detection_range is large enough
  • Predator doesn't attack: Check attack_range and that take_damage() exists on the player
  • Predator attacks too fast: Increase attack_cooldown
  • Predator falls through ground: Add CollisionShape3D to the Predator node
