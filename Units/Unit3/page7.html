Section 7: Predator AI (Chase)

Create predators that chase the player and deal damage, using Area3D for efficient detection.

Creating a Predator Animal

We'll create a predator scene that will chase the player. It will use an Area3D node to detect the player efficiently.

  • Press Ctrl + N to create a new scene
  • Add a CharacterBody3D as the root node
  • Rename it to "Predator"
  • Save the scene as "predator.tscn"
Setting Up the Node Structure
  • Add a child node: Node3D
  • Rename it to "ModelContainer"
  • Add a CollisionShape3D as a child of Predator
  • Set the shape to CapsuleShape3D
  • Set the size appropriate to your animal models
💡 What is Area3D? Area3D is a node that detects overlapping bodies. It's more efficient than checking distance every frame, especially with many animals.

Setting Up Player Detection

Add an Area3D node that will detect when the player enters the predator's detection zone.

  • Select the Predator node
  • Add a child node: Area3D
  • Rename it to "DetectionArea"
  • Add a CollisionShape3D as a child of DetectionArea
  • Set the shape to SphereShape3D
  • Set the radius to 10.0 (this is the detection range)
  • Set the Collision Mask to match the player's layer
💡 Why SphereShape? A sphere provides 360-degree detection around the predator, which is perfect for a chase behavior.

Chase Script with Area3D Detection

Add this script to the Predator node. It uses signals from the DetectionArea instead of checking distance every frame.

extends CharacterBody3D

@export var speed = 3.0
@export var attack_range = 1.5
@export var attack_cooldown = 2.0
@export var damage = 10.0

@export var animal_type: String = "wolf"

@onready var model_container = $ModelContainer
@onready var detection_area = $DetectionArea

var target: Node3D = null
var attack_timer = 0.0
var is_chasing = false
var wander_direction: Vector3
var wander_timer = 0.0

func _ready():
    load_model()
    
    # Find the player
    target = get_tree().current_scene.get_node("Player")
    if target == null:
        print("Predator: No player found!")
    
    # Connect Area3D signals
    detection_area.body_entered.connect(_on_detection_area_body_entered)
    detection_area.body_exited.connect(_on_detection_area_body_exited)
    
    randomize_wander()

func load_model():
    for child in model_container.get_children():
        child.queue_free()
    
    var model_path = ""
    match animal_type:
        "wolf":
            model_path = "res://assets/animals/wolf.glb"
        "bear":
            model_path = "res://assets/animals/bear.glb"
        "big_cat":
            model_path = "res://assets/animals/big_cat.glb"
        _:
            model_path = "res://assets/animals/default_predator.glb"
    
    if ResourceLoader.exists(model_path):
        var model = load(model_path).instantiate()
        model_container.add_child(model)
    else:
        print("Model not found: ", model_path)

func _physics_process(delta):
    # Always apply gravity
    if not is_on_floor():
        velocity += get_gravity() * delta
    
    if target == null:
        move_and_slide()
        return
    
    attack_timer = max(attack_timer - delta, 0)
    
    if is_chasing:
        # Chase the player
        var direction = (target.global_position - global_position).normalized()
        velocity.x = direction.x * speed
        velocity.z = direction.z * speed
        
        # Face the direction of movement
        if velocity.length() > 0.1:
            var target_rotation = atan2(velocity.x, velocity.z)
            rotation.y = lerp(rotation.y, target_rotation, 0.1)
        
        # Check if within attack range
        if global_position.distance_to(target.global_position) < attack_range and attack_timer == 0:
            attack_player()
    else:
        # Wander when not chasing
        wander(delta)
    
    move_and_slide()

func _on_detection_area_body_entered(body):
    if body.name == "Player":
        is_chasing = true
        print("Predator detected player!")

func _on_detection_area_body_exited(body):
    if body.name == "Player":
        is_chasing = false
        print("Predator lost player.")

func wander(delta):
    wander_timer += delta
    if wander_timer > 2.0 + randf() * 3.0:
        randomize_wander()
        wander_timer = 0.0
    
    velocity.x = wander_direction.x * speed * 0.3
    velocity.z = wander_direction.z * speed * 0.3
    
    # Face the direction of wander
    if velocity.length() > 0.1:
        var target_rotation = atan2(velocity.x, velocity.z)
        rotation.y = lerp(rotation.y, target_rotation, 0.1)

func randomize_wander():
    wander_direction = Vector3(randf_range(-1, 1), 0, randf_range(-1, 1)).normalized()

func attack_player():
    if target and target.has_method("take_damage"):
        target.take_damage(damage)
        attack_timer = attack_cooldown
        print("Predator attacked!")

Understanding the Code

  • Area3D signals - body_entered and body_exited detect when the player enters or leaves the detection zone
  • is_chasing - Boolean flag controlled by the Area3D signals
  • attack_range - Distance at which the predator can attack (checked with distance_to())
  • attack_cooldown - Prevents the predator from attacking too frequently
💡 New Concept: body_entered and body_exited are signals that fire automatically when bodies enter or leave an Area3D. This is more efficient than checking distance every frame.

Adding Danger to the World

  • Open your Environment.tscn scene
  • In the FileSystem dock, find predator.tscn
  • Drag it into the viewport multiple times
  • For each instance, select it and go to the Inspector
  • Find the animal_type property
  • Choose different predators for each instance
Example Placement
  • Wolf 1: animal_type = "wolf", speed = 4.0
  • Bear 1: animal_type = "bear", speed = 2.5, damage = 20
  • Big Cat 1: animal_type = "big_cat", speed = 5.0
⚠️ Important: Place predators away from the player's starting position! Give the player time to gather food before facing danger.

Testing Your Predators

  • Press F5 to run the game
  • Walk toward a predator
  • When you enter the detection sphere, the predator should chase you
  • If it catches you, it should attack and reduce your health
  • If you run away, the predator should stop chasing when you leave the detection sphere
  • The HUD health bar should update

Troubleshooting Common Issues

  • Predator doesn't chase: Check that the DetectionArea's sphere is large enough and Collision Mask matches the player
  • Predator doesn't attack: Check attack_range and that take_damage() exists on the player
  • Predator attacks too fast: Increase attack_cooldown
  • Predator falls through ground: Add CollisionShape3D to the Predator node
