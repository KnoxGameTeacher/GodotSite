Section 8: Hunting Mechanic

Add a hunting tool that uses a ShapeCast3D to detect and hunt prey animals, with a smoke puff effect when they're hit.

Creating the Input Action

We'll set up a single input action called "hunt" that responds to both the left mouse button and the spacebar.

  • Go to Project → Project Settings
  • Click the "Input Map" tab
  • In the "Add New Action" field, type: hunt
  • Click "Add"
  • Click the "+" icon next to your new "hunt" action
  • Choose "Mouse Button" → select "Left Mouse Button" → Click "OK"
  • If there's another button you'd like to add also, add it here now.
💡 Why a Single Action? Using one action for both inputs makes your code cleaner. Just check Input.is_action_just_pressed("hunt") and it works for both.

What is ShapeCast3D?

ShapeCast3D is like a RayCast3D but with thickness. Instead of a thin line, it casts a shape (like a sphere) forward, which makes it much more forgiving for detecting small or moving objects like animals.

  • Open your player.tscn scene
  • Select the Player (CharacterBody3D) node
  • Add a child node: ShapeCast3D
  • Rename it to "HuntCast"
Configuring the ShapeCast3D
  • In the Inspector, click the "Shape" dropdown
  • Select "New SphereShape3D"
  • Set Radius to 0.5
  • Set Target Position to (0, 0, -5)
  • Set Position to (0, 1.5, 0) (eye level)
  • Enable "Exclude Parent"
  • Set Collision Mask to match your prey's layer
💡 Why ShapeCast3D? A sphere shape means you don't have to aim with pixel-perfect precision. It's much more forgiving and works better with animated prey.

Building the Visual Effect

We'll create a reusable smoke puff scene that spawns when prey is hit.

  • Press Ctrl + N to create a new scene
  • Add a Node3D as the root
  • Rename it to "SmokePuff"
  • Add a MeshInstance3D as a child
  • In the Inspector, click the "Mesh" dropdown → select "New SphereMesh"
  • Set Radius to 0.3 and Height to 0.6
  • Save the scene as "smoke_puff.tscn"

Making It Look Like Smoke

  • Select the MeshInstance3D
  • In the Inspector, find "Material Override"
  • Click the dropdown → select "New StandardMaterial3D"
  • Click the material to edit it
  • Set Albedo color to a light gray (e.g., 0.8, 0.8, 0.8)
  • Set Alpha to 0.7
  • Under "Transparency", choose "Alpha"

Adding the Smoke Script

Add this script to the SmokePuff root node:

extends Node3D

@onready var mesh = $MeshInstance3D

func _ready():
    # Randomize initial scale for variety
    var random_scale = randf_range(0.5, 1.2)
    scale = Vector3(random_scale, random_scale, random_scale)
    
    # Randomize initial rotation for variety
    rotation.y = randf_range(0, TAU)
    
    # Animate: grow and fade out
    var tween = create_tween()
    tween.set_parallel(true)
    tween.tween_property(self, "scale", scale * 2.5, 0.5)
    tween.tween_property(mesh, "transparency", 1.0, 0.5)
    
    # Remove the smoke puff after the animation
    tween.chain().tween_callback(queue_free)
💡 New Concept: create_tween() creates an animation that runs over time. set_parallel(true) makes multiple properties animate at the same time.

  • In the Inspector, click the "Node" tab (next to Inspector)
  • Under "Groups", type "prey" and click "Add"

Then add this to the prey.gd script:

func hunted():
    # The smoke puff is spawned by the player's hunt function

Player Hunt Script

Open your player.gd script and add these elements:

# Add these at the top of your player script
@onready var hunt_cast = $HuntCast
var smoke_puff_scene = preload("res://smoke_puff.tscn")

# Add this to _physics_process() (or wherever you check input)
func _physics_process(delta):
    # ... your existing movement code ...
    
    if Input.is_action_just_pressed("hunt"):
        hunt()
    
    move_and_slide()

# The hunt function
func hunt():
    # Force the shapecast to update immediately
    hunt_cast.force_shapecast_update()
    
    if hunt_cast.is_colliding():
        # Get all colliders hit by the shape
        for i in range(hunt_cast.get_collision_count()):
            var collider = hunt_cast.get_collider(i)
            
            if collider.is_in_group("prey"):
                # Spawn smoke puff at the prey's position
                spawn_smoke_puff(collider.global_position)
                
                # Hunt the prey
                collider.hunted()
                
                # Restore hunger
                eat(20)
                print("Hunted prey! Hunger restored.")
                return  # Only hunt one prey at a time

func spawn_smoke_puff(spawn_position):
    var smoke = smoke_puff_scene.instantiate()
    smoke.global_position = spawn_position
    get_parent().add_child(smoke)

Understanding the Code

  • force_shapecast_update() - Makes the shapecast check for collisions immediately
  • get_collision_count() - Returns how many objects the shapecast is hitting
  • get_collider(i) - Gets the specific collider at index i
  • is_in_group("prey") - Checks if the object belongs to the "prey" group
  • preload() - Loads the smoke puff scene once for reuse
💡 New Concept: for i in range() loops through all collisions. This is important because the shapecast might hit multiple prey at once!

Testing Your Hunting System

  • Press F5 to run the game
  • Walk toward a prey animal
  • Press Space or Left Mouse Button
  • A smoke puff should appear at the prey's location
  • The prey should disappear
  • Your hunger bar should increase by 20

Troubleshooting Common Issues

  • No prey hit: Check that the ShapeCast3D's Collision Mask matches the prey's layer
  • Smoke puff doesn't appear: Check that smoke_puff.tscn exists and the path is correct
  • Prey doesn't disappear: Check that the Prey is in the "prey" group
  • Hunting hits trees: The shape is large - this is expected! The prey check filters them out
  • Smoke puff is too small/large: Adjust the radius in smoke_puff.tscn
🎉 Congratulations! You now have a working hunting mechanic with visual feedback! You can hunt prey to restore hunger, and the smoke puff makes it feel satisfying.
