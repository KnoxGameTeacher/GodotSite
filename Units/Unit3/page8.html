Section 8: Hunting Mechanic

Add a hunting tool that uses raycasting to hunt prey animals and restore hunger.

Section Progress: 0%

What is Raycasting?

Raycasting is like shooting an invisible laser from a point in a direction. It detects the first object it hits and tells you what it hit. This is perfect for hunting!

  • Open your player.tscn scene
  • Select the Player (CharacterBody3D) node
  • Add a child node: RayCast3D
  • Rename it to "HuntRay"
Configuring the RayCast3D
  • Select the HuntRay node
  • In the Inspector, set Target Position to (0, 0, -10)
  • This makes the ray point forward 10 meters
  • Set Collision Mask to the layer your prey is on (usually Layer 1)
  • Enable Hit From Inside if the ray starts inside the player
💡 New Concept: RayCast3D is a node that detects objects in a straight line. It's commonly used for shooting, line of sight, and interaction systems.

Setting Up the Hunt Action

We'll use the mouse click or a keyboard key to trigger the hunt action.

  • Open your player.gd script
  • Add these variables and functions:
# Add to player.gd
@onready var hunt_ray = $HuntRay

func _input(event):
    # Hunt with Left Mouse Click
    if event is InputEventMouseButton and event.pressed and event.button_index == MOUSE_BUTTON_LEFT:
        hunt()
    
    # Alternative: Hunt with Spacebar
    if event is InputEventKey and event.pressed and event.keycode == KEY_SPACE:
        hunt()

func hunt():
    # Force the ray to update
    hunt_ray.force_raycast_update()
    
    if hunt_ray.is_colliding():
        var collider = hunt_ray.get_collider()
        print("Hunting target: ", collider.name)
        
        # Check if the collider is a prey animal
        if collider.is_in_group("prey"):
            # Successfully hunted!
            collider.hunted()
            eat(20)  # Restore hunger
            print("Hunted prey! Hunger restored.")

Understanding the Code

  • _input(event) - Handles input events (mouse clicks, keyboard presses)
  • MOUSE_BUTTON_LEFT - Detects left mouse click
  • force_raycast_update() - Makes the ray check for collisions immediately
  • is_colliding() - Returns true if the ray hit something
  • get_collider() - Returns the object the ray hit
  • is_in_group("prey") - Checks if the object belongs to the "prey" group
💡 New Concept: Groups are a way to tag nodes. We'll add prey animals to the "prey" group so the ray can identify them specifically.

Making Hunting Feel Satisfying

Add visual feedback when you hunt to make the action feel responsive.

In player.gd, update the hunt() function:

func hunt():
    hunt_ray.force_raycast_update()
    
    if hunt_ray.is_colliding():
        var collider = hunt_ray.get_collider()
        var hit_point = hunt_ray.get_collision_point()
        
        # Add hit effect (particle, flash, or glow)
        add_hit_effect(hit_point)
        
        if collider.is_in_group("prey"):
            collider.hunted()
            eat(20)
            print("Hunted prey! Hunger restored.")
        else:
            print("Not a prey animal.")
    else:
        print("Missed!")

Add a simple hit effect function:

func add_hit_effect(position):
    # Simple flash effect - you can replace with particles later
    var flash = MeshInstance3D.new()
    flash.mesh = SphereMesh.new()
    flash.scale = Vector3(0.3, 0.3, 0.3)
    flash.position = position
    flash.material_override = StandardMaterial3D.new()
    flash.material_override.albedo_color = Color(1, 0.5, 0, 1)  # Orange flash
    
    get_parent().add_child(flash)
    
    # Fade out and remove
    var tween = create_tween()
    tween.tween_property(flash, "scale", Vector3(2, 2, 2), 0.5)
    tween.parallel().tween_property(flash, "modulate", Color(1, 1, 1, 0), 0.5)
    tween.tween_callback(flash.queue_free)
💡 Pro Tip: Visual feedback is crucial for satisfying game feel. Even a simple flash or pop effect makes hunting feel more impactful.

Equipping a Hunting Tool

Add a visual representation of a hunting tool (spear, bow, staff) to the player's hand.

  • Open player.tscn
  • Select the Player node
  • Add a child node: MeshInstance3D
  • Rename it to "HuntingTool"
  • Set the mesh to a simple CylinderMesh (spear) or import a weapon model

Position and rotate the tool to appear in the player's hand:

# In the Player script, adjust the tool position
func _ready():
    # Position the tool in front of the camera
    $HuntingTool.position = Vector3(0.3, -0.2, -0.5)
    $HuntingTool.rotation = Vector3(0.2, 0, 0.5)
💡 Pro Tip: A visible hunting tool helps players understand the mechanic immediately. You can animate it to swing or extend when hunting!

Testing Your Hunting System

  • Press F5 to run the game
  • Walk toward a prey animal
  • Click Left Mouse Button or press Space to hunt
  • The prey should disappear
  • Your hunger bar should increase by 20
  • If you miss, you should see a "Missed!" message

Troubleshooting Common Issues

  • Prey doesn't disappear: Check that the Prey is in the "prey" group
  • Hunger doesn't increase: Check that eat() is called and working
  • Ray doesn't hit: Check that Collision Mask matches the Prey's layer
  • Hunting tool doesn't appear: Check the position and rotation of the tool
  • No feedback on hit: Ensure the visual feedback code runs
