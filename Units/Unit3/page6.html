Section 6: Prey AI (Flee)

Create animals that run away from the player, with support for multiple animal models in a single scene.

Section Progress: 0%
1

Creating a Prey Animal

We'll create a single scene that can be used for any prey animal (rabbits, deer, squirrels, etc.).

  • Press Ctrl + N to create a new scene
  • Add a CharacterBody3D as the root node
  • Rename it to "Prey"
  • Save the scene as "prey.tscn"
Setting Up the Node Structure
  • Add a child node: Node3D
  • Rename it to "ModelContainer"
  • This node will hold the 3D model
  • Add a CollisionShape3D as a child of Prey
  • Set the shape to CapsuleShape3D or a shape appropriate to your animal models
  • Adjust the size of the collision shape to fit your animal model
💡 Why a ModelContainer? This makes it easy to swap different animal models without affecting the collision or behavior logic.

Getting Animal Models

You'll need 3D animal models for your prey. Here are some options:

  • Kenney Animal Pack: https://kenney.nl/assets/animal-pack
  • Itch.io Free 3D Assets: Search for "animals"
Importing Models
  • Download your chosen animal models (.glb or .gltf)
  • Create a folder: assets/animals/
  • Drag the model files into this folder
  • You may need to assign textures manually and do an advanced reimport to get your animations
💡 Pro Tip: If you don't have animal models yet, you can use primitive shapes (BoxMesh, CapsuleMesh) as placeholders. The script will work the same way!

Flee Script with Multiple Models

Add this script to the Prey node. It includes support for selecting different animal models in the Inspector.

extends CharacterBody3D


@export var speed = 4.0
@export var detection_range = 8.0
@export var flee_distance = 15.0

@export var animal_type: String
@onready var model_container: Node3D = $ModelContainer
@onready var ground_ray: RayCast3D = $GroundRay

var target: Node3D
var flee_direction: Vector3
var is_fleeing = false
var wander_direction: Vector3
var wander_timer = 0.0
var gravity = -9.8

func _ready():
	load_model()
	
	target = get_tree().current_scene.get_node("Player")
	if target == null:
		print("Prey: No Player Found")
		
	randomize_wander()
	
func load_model():
	var model_path = ""
	match animal_type:
		"chick":
			model_path = "res://assets/animals/animal-chick.glb"
		"crab":
			model_path = "res://assets/animals/animal-crab.glb"
	if ResourceLoader.exists(model_path):
		var model = load(model_path).instantiate()
		model_container.add_child(model)
	else:
		print("Prey model not found", model_path)

func randomize_wander():
	wander_direction = Vector3(randf_range(-1, 1), 0, randf_range(-1, 1)).normalized()
	
func wander(delta):
	wander_timer += delta
	if wander_timer > 2.0 + randf() * 3.0:
		randomize_wander()
		wander_timer = 0.0
	velocity = wander_direction * speed * 0.5

func _physics_process(delta: float) -> void:
	velocity.y += gravity * delta
		# Snap to ground using raycast
	ground_ray.global_position = global_position
	ground_ray.force_raycast_update()
	if ground_ray.is_colliding():
		var hit_point = ground_ray.get_collision_point()
		var ground_height = hit_point.y + 0.3  # 0.3 = half the animal's height
		
		# If animal is above ground, lower it
		if global_position.y > ground_height:
			global_position.y = ground_height
			velocity.y = 0.0
	
	# If on floor, ensure we stay on the ground
	if is_on_floor():
		velocity.y = 0.0
	if target == null:
		return
	var distance_to_player = global_position.distance_to(target.global_position)
	if distance_to_player < detection_range:
		is_fleeing = true
		flee_direction = (global_position - target.global_position).normalized()
		velocity = flee_direction * speed
		if distance_to_player > detection_range:
			is_fleeing = false
			randomize_wander()
	else:
		is_fleeing = false
		wander(delta)
		
	if velocity.length() > 0.1:
		var target_rotation = atan2(velocity.x, velocity.z)
		rotation.y = lerp(rotation.y, target_rotation, 0.1)
	move_and_slide()

Understanding the Model Selection Code

  • @export var animal_type - Dropdown in Inspector to choose which animal
  • load_model() - Loads the selected model when the scene starts
  • match - A switch statement that picks the correct model path
  • model_container - The Node3D that holds the model
  • queue_free() - Removes the old model before loading a new one
💡 New Concept: match is a powerful conditional statement in GDScript. It's like a switch statement and is perfect for selecting between multiple options.

Using Area3D for Detection with Customizable Range

Instead of calculating distance in the script, we'll use an Area3D node for detection. This is more efficient with many animals, and we'll make the detection range editable per animal instance while keeping our ground collision checks.

Step 1: Add the DetectionArea Node
  • Select the Prey node
  • Add a child node: Area3D
  • Rename it to "DetectionArea"
  • Add a CollisionShape3D as a child of DetectionArea
  • Set the shape to SphereShape3D with radius 8.0 (this will be overridden by the script)
Step 2: Update Your Prey Script

Append prey.gd with this script:

extends CharacterBody3D


#...original code
@export var detection_range = 8.0
@onready var detection_area: Area3D = $DetectionArea

var player_in_range = false

func _ready():
    load_model()
    
    # Set the detection area radius from the exported variable
    update_detection_range()
    
    target = get_tree().current_scene.get_node("Player")
    if target == null:
        print("Prey: No Player Found")
    
    # Connect signals
    detection_area.body_entered.connect(_on_detection_area_body_entered)
    detection_area.body_exited.connect(_on_detection_area_body_exited)
    
    randomize_wander()

func update_detection_range():
    # Get the CollisionShape3D child of DetectionArea
    var shape = detection_area.get_node("CollisionShape3D")
    if shape and shape.shape is SphereShape3D:
        shape.shape.radius = detection_range
        print("Detection range set to: ", detection_range)

func _on_detection_area_body_entered(body):
    if body.name == "Player":
        player_in_range = true

func _on_detection_area_body_exited(body):
    if body.name == "Player":
        player_in_range = false


func _physics_process(delta: float) -> void:
   #..other physics code..
    # Use Area3D detection instead of distance check
    if player_in_range:
        is_fleeing = true
        flee_direction = (global_position - target.global_position).normalized()
        velocity.x = flee_direction.x * speed
        velocity.z = flee_direction.z * speed
        
        # Check if we've fled far enough
        var distance_to_player = global_position.distance_to(target.global_position)
        if distance_to_player > flee_distance:
            is_fleeing = false
            randomize_wander()
    else:
        is_fleeing = false
        wander(delta)

Key Changes Explained

  • @export var detection_range - Now editable per animal in the Inspector
  • update_detection_range() - Dynamically sets the SphereShape3D radius
  • player_in_range - Tracks if the player is inside the detection area
  • body_entered/body_exited signals - Update player_in_range automatically
  • Distance check removed - Detection is now handled by Area3D
  • Ground collision preserved - RayCast3D ground snapping still works
Using the Editable Detection Range

Each Prey instance in the Inspector now has a detection_range property. This allows you to give different animals different awareness distances!

  • Chick: detection_range = 6.0 (less alert)
  • Crab: detection_range = 10.0 (more alert)
💡 Pro Tip: To see the detection range in the editor, select the DetectionArea node, go to the "Gizmo" tab in the Inspector, and enable "Show Collision Shapes". You'll see the sphere update as you adjust the radius!

Testing Your Prey Animals

  • Press F5 to run the game
  • Walk toward each type of prey animal
  • Each animal should flee away from you
  • Different animals should have different models
  • If you stop chasing, the animal should wander again

Troubleshooting Common Issues

  • Prey doesn't move: Check that speed is set and the script is attached
  • Prey falls through ground: Add a CollisionShape3D to the Prey node
  • Prey ignores player: Check that detection_range is large enough
  • Model doesn't appear: Check that the model path in the script matches your file location
  • All animals look the same: Verify each instance has a different animal_type selected
