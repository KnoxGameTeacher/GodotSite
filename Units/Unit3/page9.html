Creating a Win Condition

Players need a goal to work toward. We'll add a win condition based on survival time.

  • Open player.gd
  • Add a survival timer and win check:
# Add to player.gd
var survival_time = 0.0
var win_time = 120.0  # Win after 2 minutes (in seconds)

func _process(delta):
    # Track survival time
    survival_time += delta
    
    # Check win condition
    if survival_time >= win_time:
        win_game()

func win_game():
    # Show win screen
    get_tree().change_scene_to_file("res://Win.tscn")
    
    # Optionally save stats
    print("You survived!", survival_time, "seconds!")
💡 Alternative Win Conditions: You could also win by collecting a certain number of food items, hunting a certain number of prey, or reaching a specific location.

Scripting Menu Transitions

Start.tscn Script
extends Control

func _ready():
    $StartButton.pressed.connect(_on_start_pressed)
    $QuitButton.pressed.connect(_on_quit_pressed)

func _on_start_pressed():
    get_tree().change_scene_to_file("res://Environment.tscn")

func _on_quit_pressed():
    get_tree().quit()
Win.tscn Script
extends Control

func _ready():
    # Display survival time
    if get_tree().current_scene.has_method("get_survival_time"):
        var time = get_tree().current_scene.get_survival_time()
        $TimeLabel.text = "You survived: " + str(int(time)) + " seconds!"
    
    $PlayAgainButton.pressed.connect(_on_play_again_pressed)
    $MainMenuButton.pressed.connect(_on_main_menu_pressed)

func _on_play_again_pressed():
    get_tree().reload_current_scene()

func _on_main_menu_pressed():
    get_tree().change_scene_to_file("res://Start.tscn")
💡 Pro Tip: Use reload_current_scene() to restart the game without reloading the entire project.

Adding Audio to Your Game

Sound effects make games feel alive and responsive.

  • Find free sound effects (e.g., from Kenney Audio or Freesound.org)
  • Create an AudioStreamPlayer node for each sound
  • Place them in your Player scene
Add to player.gd
# Add sound nodes
@onready var hunt_sound = $HuntSound
@onready var hurt_sound = $HurtSound
@onready var footstep_sound = $FootstepSound

func hunt():
    hunt_ray.force_raycast_update()
    
    if hunt_ray.is_colliding():
        var collider = hunt_ray.get_collider()
        
        if collider.is_in_group("prey"):
            collider.hunted()
            eat(20)
            hunt_sound.play()  # Play hunting sound
        else:
            # Play miss sound
            hunt_sound.pitch_scale = 0.5
            hunt_sound.play()
    else:
        # Play miss sound
        hunt_sound.pitch_scale = 0.5
        hunt_sound.play()

func take_damage(amount):
    health -= amount
    health = max(health, 0)
    hurt_sound.play()  # Play hurt sound
    update_hud()
    
    if health <= 0:
        game_over()

func _physics_process(delta):
    # ... movement code ...
    
    # Play footstep sounds when walking
    if velocity.length() > 0.1 and is_on_floor():
        # Play footstep sound (check timer)
        footstep_timer += delta
        if footstep_timer > 0.5:
            footstep_sound.play()
            footstep_timer = 0.0
💡 Pro Tip: You can adjust pitch_scale to make sounds slightly different each time, creating variety.

Making Your UI Shine

Polished UI helps players understand the game state quickly.

  • Add color gradients to health and hunger bars
  • Add icons for health and hunger (heart, food)
  • Add a timer display showing survival time
  • Add subtle animations (pulsing bars, smooth transitions)
Enhanced HUD Script
extends CanvasLayer

@onready var health_bar = $HealthBar
@onready var hunger_bar = $HungerBar
@onready var time_label = $TimeLabel
@onready var player

func _ready():
    player = get_node("../Player")
    if player:
        update_display()

func _process(delta):
    if player:
        # Update survival time display
        var time = player.survival_time
        var minutes = int(time / 60)
        var seconds = int(time) % 60
        time_label.text = str(minutes).pad_zeros(2) + ":" + str(seconds).pad_zeros(2)
        
        # Colorize bars based on values
        update_bar_colors()

func update_display():
    if player:
        health_bar.value = player.health
        hunger_bar.value = player.hunger
        
        # Update labels if they exist
        if health_bar.has_node("Label"):
            health_bar.get_node("Label").text = str(int(player.health)) + "%"
        if hunger_bar.has_node("Label"):
            hunger_bar.get_node("Label").text = str(int(player.hunger)) + "%"

func update_bar_colors():
    # Health bar color: Green (high) → Yellow → Red (low)
    var health_ratio = health_bar.value / health_bar.max_value
    if health_ratio > 0.5:
        health_bar.modulate = Color(0, 1, 0, 1)  # Green
    elif health_ratio > 0.25:
        health_bar.modulate = Color(1, 1, 0, 1)  # Yellow
    else:
        health_bar.modulate = Color(1, 0, 0, 1)  # Red
    
    # Hunger bar: Full (Green) → Empty (Red)
    var hunger_ratio = hunger_bar.value / hunger_bar.max_value
    if hunger_ratio > 0.5:
        hunger_bar.modulate = Color(0.2, 0.8, 0.2, 1)
    elif hunger_ratio > 0.25:
        hunger_bar.modulate = Color(1, 0.7, 0.1, 1)  # Orange
    else:
        hunger_bar.modulate = Color(1, 0.1, 0.1, 1)  # Red
💡 Pro Tip: Color-coding bars helps players understand their status at a glance, even without reading numbers.

Testing Your Full Game

  • Set Start.tscn as the main scene in Project Settings
  • Press F5 to run the game
  • Click "Start Game" to begin
  • Survive for 2 minutes to reach the win screen
  • Let your health reach 0 to see the Game Over screen
  • Test all menu transitions (Play Again, Main Menu, Quit)

↓ (Press "Main Menu")

Environment.tscn → (Health reaches 0) → GameOver.tscn

Environment.tscn (Reset)

Troubleshooting

  • Win scene doesn't load: Check that win_time is set and the path to Win.tscn is correct
  • Game Over doesn't trigger: Check that take_damage() calls game_over()
  • Scene transitions fail: Check that scene file paths are correct (case-sensitive!)
