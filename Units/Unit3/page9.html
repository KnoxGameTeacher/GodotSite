Section 9: Character Select Screen

Create a character selection screen that allows players to choose between two characters before starting the game.

Section Progress: 0%
1

Creating the Scene

  • Press Ctrl + N to create a new scene
  • Add a Control node as the root
  • Rename it to "CharacterSelect"
  • Save the scene as "character_select.tscn"
Setting Up the Layout
  • Select the root Control node
  • In the Inspector, set Layout to "Full Rect"
  • Add a ColorRect as a child for a background
  • Add a Label with text "Choose Your Character"
💡 Pro Tip: A Control node with Full Rect layout ensures your UI scales properly to any screen size.
Figure 9.1: Creating the Character Select scene with Control root
2

Creating the Character Buttons

  • Add a HBoxContainer node as a child of the root Control
  • Add a Button node as a child of HBoxContainer
  • Rename it to "Character1Button"
  • Set its Text property to "Character 1"
  • Add another Button as a child of HBoxContainer
  • Rename it to "Character2Button"
  • Set its Text property to "Character 2"
Adding Character Previews (Optional)
  • Add a TextureRect above each button
  • Load a preview image of each character
  • This gives visual feedback for the selection
💡 Pro Tip: Using HBoxContainer automatically spaces the buttons horizontally. You can use VBoxContainer for vertical stacking.
Figure 9.2: Adding Character 1 and Character 2 buttons
3

UI Elements

  • Add a Label as a child of the root Control
  • Rename it to "SelectionLabel"
  • Set its Text to "No character selected"
  • Add a Button as a child of the root Control
  • Rename it to "StartButton"
  • Set its Text to "Start Game"
Positioning with Layout
  • Select the SelectionLabel
  • Set Horizontal Alignment to "Center"
  • Select the StartButton
  • Set Horizontal Alignment to "Center"
💡 Pro Tip: Use Anchor and Margin properties to position elements precisely on the screen.
Figure 9.3: Adding the selection label and Start button

Character Select Script

Attach this script to the root Control node:

extends Control

@onready var character1_button = $Character1Button
@onready var character2_button = $Character2Button
@onready var selection_label = $SelectionLabel
@onready var start_button = $StartButton

var selected_character = ""

func _ready():
    # Connect button signals
    character1_button.pressed.connect(_on_character1_pressed)
    character2_button.pressed.connect(_on_character2_pressed)
    start_button.pressed.connect(_on_start_pressed)
    
    # Disable Start button initially
    start_button.disabled = true
    update_ui()

func _on_character1_pressed():
    selected_character = "character1"
    update_ui()

func _on_character2_pressed():
    selected_character = "character2"
    update_ui()

func _on_start_pressed():
    if selected_character != "":
        # Store the selection in a global variable
        Global.selected_character = selected_character
        get_tree().change_scene_to_file("res://Environment.tscn")
    else:
        selection_label.text = "Please select a character!"

func update_ui():
    if selected_character != "":
        selection_label.text = "Selected: " + selected_character.capitalize()
        start_button.disabled = false
        
        # Highlight selected button
        character1_button.modulate = Color(1, 1, 1, 1)
        character2_button.modulate = Color(1, 1, 1, 1)
        
        if selected_character == "character1":
            character1_button.modulate = Color(0, 1, 0, 1)
        elif selected_character == "character2":
            character2_button.modulate = Color(0, 1, 0, 1)
    else:
        selection_label.text = "No character selected"
        start_button.disabled = true
💡 New Concept: button.pressed.connect() connects a button click to a function. When the button is clicked, the function runs.

Storing the Selection

To use the selected character in the game, create an autoload script:

  • Create a new script called "Global.gd"
extends Node

var selected_character = ""
  • Go to Project → Project Settings → Autoload
  • Add Global.gd with the name "Global"
Using the Selection in Player.gd
# In player.gd - _ready() or load_model()
func load_model():
    var character_name = Global.selected_character
    var model_path = ""
    match character_name:
        "character1":
            model_path = "res://assets/characters/character1.glb"
        "character2":
            model_path = "res://assets/characters/character2.glb"
        _:
            model_path = "res://assets/characters/default.glb"
    
    # Load and instantiate the model...
⚠️ Important: The Autoload must be set up before the game runs. The character select scene should be the first scene loaded.

6

Making It the Starting Point

  • Go to Project → Project Settings
  • Click the "General" tab
  • Find Application → Run → Main Scene
  • Click the folder icon and select "character_select.tscn"
  • Click "Close"
Testing
  • Press F5 to run the game
  • You should see the Character Select screen
  • Click Character 1 or Character 2
  • The label should update to show your selection
  • Click "Start Game" to load the environment
🎉 Congratulations! You now have a character select screen that passes the player's choice into the game!
