Creating a Win Condition

  • Open player.gd
  • Add a survival timer and win check:
var survival_time = 0.0
var win_time = 120.0

func _process(delta):
    survival_time += delta
    if survival_time >= win_time:
        win_game()

func win_game():
    get_tree().change_scene_to_file("res://Win.tscn")
💡 Alternative Win Conditions: You could also win by collecting a certain number of food items or hunting a certain number of prey.

Scripting Menu Transitions

Start.tscn Script
extends Control

func _ready():
    $StartButton.pressed.connect(_on_start_pressed)
    $QuitButton.pressed.connect(_on_quit_pressed)

func _on_start_pressed():
    get_tree().change_scene_to_file("res://character_select.tscn")

func _on_quit_pressed():
    get_tree().quit()
Win.tscn Script
extends Control

func _ready():
    $PlayAgainButton.pressed.connect(_on_play_again_pressed)
    $MainMenuButton.pressed.connect(_on_main_menu_pressed)

func _on_play_again_pressed():
    get_tree().reload_current_scene()

func _on_main_menu_pressed():
    get_tree().change_scene_to_file("res://Start.tscn")
💡 Pro Tip: Use reload_current_scene() to restart the game without reloading the entire project.

Adding Audio to Your Game

  • Find free sound effects (e.g., from Kenney Audio)
  • Create an AudioStreamPlayer node for each sound
  • Place them in your Player scene
Add to player.gd
@onready var hunt_sound = $HuntSound
@onready var hurt_sound = $HurtSound

func hunt():
    if hunt_ray.is_colliding():
        var collider = hunt_ray.get_collider()
        if collider.is_in_group("prey"):
            collider.hunted()
            eat(20)
            hunt_sound.play()
        else:
            hunt_sound.pitch_scale = 0.5
            hunt_sound.play()

func take_damage(amount):
    health -= amount
    health = max(health, 0)
    hurt_sound.play()
    update_hud()
💡 Pro Tip: You can adjust pitch_scale to make sounds slightly different each time, creating variety.

Making Your UI Shine

  • Add color gradients to health and hunger bars
  • Add icons for health and hunger (heart, food)
  • Add a timer display showing survival time
  • Add subtle animations (pulsing bars, smooth transitions)
Enhanced HUD Script
extends CanvasLayer

@onready var health_bar = $HealthBar
@onready var hunger_bar = $HungerBar
@onready var time_label = $TimeLabel
var player

func _ready():
    player = get_node("../Player")
    if player:
        update_display()

func _process(delta):
    if player:
        var time = player.survival_time
        var minutes = int(time / 60)
        var seconds = int(time) % 60
        time_label.text = str(minutes).pad_zeros(2) + ":" + str(seconds).pad_zeros(2)
        update_bar_colors()

func update_display():
    if player:
        health_bar.value = player.health
        hunger_bar.value = player.hunger

func update_bar_colors():
    var health_ratio = health_bar.value / health_bar.max_value
    if health_ratio > 0.5:
        health_bar.modulate = Color(0, 1, 0, 1)
    elif health_ratio > 0.25:
        health_bar.modulate = Color(1, 1, 0, 1)
    else:
        health_bar.modulate = Color(1, 0, 0, 1)
💡 Pro Tip: Color-coding bars helps players understand their status at a glance, even without reading numbers.
