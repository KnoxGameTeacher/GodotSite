Section 5: Hunger & Health Systems

Add survival meters for hunger and health, with a Heads-Up Display (HUD) to track your status.

Setting Up Player Stats

Open your player.gd script and add hunger and health variables:

extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5

# Survival stats
var health = 100.0
var max_health = 100.0
var hunger = 100.0
var max_hunger = 100.0
var hunger_rate = 2.0  # Hunger lost per second

@onready var animation_player = $AnimationPlayer
@onready var character = $character

var current_animation = "idle"

func _ready():
    # Start the hunger timer
    var hunger_timer = Timer.new()
    hunger_timer.wait_time = 1.0
    hunger_timer.timeout.connect(_on_hunger_tick)
    add_child(hunger_timer)
    hunger_timer.start()

func _on_hunger_tick():
    # Decrease hunger over time
    hunger -= hunger_rate
    hunger = max(hunger, 0)
    
    # If hunger reaches 0, start losing health
    if hunger <= 0:
        health -= 5.0
        health = max(health, 0)
    
    # Update the HUD
    update_hud()

func take_damage(amount):
    health -= amount
    health = max(health, 0)
    update_hud()
    
    if health <= 0:
        game_over()

func heal(amount):
    health = min(health + amount, max_health)
    update_hud()

func eat(amount):
    hunger = min(hunger + amount, max_hunger)
    update_hud()

func update_hud():
    # This will be connected to the UI in Step 2
    pass

func game_over():
    get_tree().change_scene_to_file("res://GameOver.tscn")

Understanding the Code

  • health and hunger - Track the player's status (0-100)
  • hunger_rate - How fast hunger decreases (2 points per second)
  • Timer - Creates a timer that fires every second
  • _on_hunger_tick() - Called each second; decreases hunger, then health if hunger is 0
  • max() - Prevents values from going below 0
  • min() - Prevents values from exceeding the maximum
💡 New Concept: Timer nodes are used to trigger events at regular intervals. Here, we use one to simulate hunger decreasing over time.

Building the Heads-Up Display

We'll create a simple HUD using CanvasLayer and TextureProgressBar nodes.

  • Open your Environment.tscn scene
  • Add a CanvasLayer node as a child of the root
  • Rename it to "HUD"
Adding Health Bar
  • Add a TextureProgressBar as a child of HUD
  • Rename it to "HealthBar"
  • In the Inspector, set Min Value to 0
  • Set Max Value to 100
  • Set Value to 100
  • Set the FILL color to Red
  • Position it in the top-left corner
Adding Hunger Bar
  • Add another TextureProgressBar as a child of HUD
  • Rename it to "HungerBar"
  • Set Min Value to 0, Max Value to 100
  • Set Value to 100
  • Set the FILL color to Green
  • Position it below the Health Bar
💡 Pro Tip: You can add labels above each bar using Label nodes to show "Health" and "Hunger" text.

Updating the HUD in Real-Time

Add a script to the HUD (CanvasLayer) node:

extends CanvasLayer

@onready var health_bar = $HealthBar
@onready var hunger_bar = $HungerBar
@onready var health_label = $HealthLabel
@onready var hunger_label = $HungerLabel

var player

func _ready():
    # Find the player
    player = get_node("../Player")
    if player:
        update_display()

func update_display():
    if player:
        health_bar.value = player.health
        hunger_bar.value = player.hunger
        
        # Update labels if they exist
        if health_label:
            health_label.text = "Health: " + str(int(player.health)) + "%"
        if hunger_label:
            hunger_label.text = "Hunger: " + str(int(player.hunger)) + "%"

Then update the player.gd script to call the HUD:

# Add this to player.gd
func update_hud():
    var hud = get_node("../HUD")
    if hud:
        hud.update_display()
⚠️ Important: Make sure the HUD is a sibling of the Player node (both children of Environment) so the path ../HUD works correctly.

Game Over Screen

When the player's health reaches 0, we'll show a Game Over screen.

  • Create a new scene with Control as the root node
  • Add a Label with text "Game Over"
  • Add a Button with text "Try Again"
  • Add a Button with text "Main Menu"
  • Save as "GameOver.tscn"

Add this script to the GameOver scene:

extends Control

func _ready():
    $TryAgainButton.pressed.connect(_on_try_again_pressed)
    $MainMenuButton.pressed.connect(_on_main_menu_pressed)

func _on_try_again_pressed():
    get_tree().reload_current_scene()

func _on_main_menu_pressed():
    get_tree().change_scene_to_file("res://Start.tscn")
💡 Pro Tip: get_tree().reload_current_scene() reloads the current scene, which resets the player and all game objects to their starting state.

Testing Your Survival Systems

  • Press F5 to run the game
  • Watch the hunger bar decrease over time
  • When hunger reaches 0, health should start decreasing
  • If health reaches 0, the Game Over scene should appear
  • Click "Try Again" to restart

Testing with Debug Commands

To test more quickly, add these debug commands to your player.gd:

# Add to player.gd
func _input(event):
    if event is InputEventKey and event.pressed:
        if event.keycode == KEY_H:
            # Press H to heal
            heal(20)
        elif event.keycode == KEY_E:
            # Press E to eat (restore hunger)
            eat(20)
