Section 4: Third-Person Camera

Add a third-person camera with SpringArm3D that follows the player and rotates with the mouse.

Section Progress: 0%
1

What is SpringArm3D?

SpringArm3D is a special node that acts like a selfie stick for your camera. It:

  • Follows the player automatically
  • Detects walls and moves the camera closer to avoid clipping
  • Allows smooth rotation around the player

Open your Environment.tscn and add the SpringArm3D:

  • Select the root Node3D (Environment)
  • Click the "+" (Add Child Node) icon
  • Search for and add a SpringArm3D node
  • Rename it to "CameraArm"
  • Add a RayCast3D node as a child of the SpringArm3D
  • Rename the RayCast3D to "GroundCheck"
💡 Important: The SpringArm3D must be a sibling of the Player node, not a child. This allows it to follow the player independently.

Setting Up the Camera

Add a Camera3D as a child of the SpringArm3D:

  • Select the CameraArm (SpringArm3D) node
  • Add a child node: Camera3D
  • Rename it to "Camera3D"
  • Select the CameraArm node again
  • In the Inspector, set the "Spring Length" to 8.0
  • Set "Margin" to 0.5
  • Set "Collision Mask" to 1
💡 Pro Tip: Spring Length of 8 is a good starting point for a distant view. You can adjust it later based on your preference.

CameraArm Script (Using SpringArm's Built-in Rotation)

Add this script to the CameraArm (SpringArm3D) node:

extends SpringArm3D

@export var target: Node3D
@export var rotation_speed: float = 0.005
@export var min_height: float = 0.3
@onready var ground_check: RayCast3D = $GroundCheck

func _ready():
	if target == null:
		target = get_node("../Player")
	Input.set_mouse_mode(Input.MOUSE_MODE_CAPTURED)
	
	ground_check.target_position = Vector3(0, -spring_length, 0)

func _input(event):
	if event is InputEventMouseMotion and Input.get_mouse_mode() == Input.MOUSE_MODE_CAPTURED:
		# Directly modify the SpringArm's rotation
		rotation.y -= event.relative.x * rotation_speed
		rotation.x -= event.relative.y * rotation_speed
		rotation.x = clamp(rotation.x, -0.5, 1.0)

func _physics_process(delta):
	if target == null:
		return
	# Move to target position
	global_position = target.global_position
	
		# Check if camera is below ground
	ground_check.global_position = global_position
	ground_check.force_raycast_update()
	
	if ground_check.is_colliding():
		var hit_y = ground_check.get_collision_point().y
		if global_position.y < hit_y + min_height:
			global_position.y = hit_y + min_height

Understanding the Code

  • @export var target - The player node the camera follows
  • Input.set_mouse_mode() - Captures the mouse for camera control
  • rotation.y - Directly sets the SpringArm's horizontal rotation
  • rotation.x - Directly sets the SpringArm's vertical rotation
  • clamp(rotation.x, -0.5, 1.0) - Limits vertical rotation to prevent flipping
  • global_position = target.global_position - Makes the SpringArm follow the player
  • RayCast3D - Checks if the camera is below the ground and adjusts its height to avoid clipping
⚠️ Important: This script modifies the SpringArm's built-in rotation property directly. The Camera3D child will automatically point in the direction of the SpringArm's rotation. Do NOT use look_at() - it will fight with the SpringArm's internal mechanics!

Linking the Camera to the Player

With the CameraArm node selected, go to the Inspector:

  • Find the "Target" property under Script Variables
  • Click the dropdown and select the Player node
  • If you can't see the Player node, make sure it's in the scene
💡 Quick Check: If the script can't find the target, it will print "CameraArm: No target found!" in the console.

Why Camera-Relative Movement?

By default, WASD moves the player along the world axes (X and Z). When the camera rotates, this feels unnatural because W doesn't move "forward" relative to the camera.

We need to make the player's movement relative to the camera's orientation. Here's the updated player script:

extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5

@onready var animation_player = $AnimationPlayer
@onready var character = $character

var current_animation = "idle"

func _physics_process(delta: float) -> void:
    # Gravity
    if not is_on_floor():
        velocity += get_gravity() * delta

    # Jump
    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = JUMP_VELOCITY

    # Get camera-relative movement
    var input_dir = Input.get_vector("left", "right", "up", "down")
    var camera = get_viewport().get_camera_3d()
    
    if camera:
        # Get camera's forward and right vectors, flattened to horizontal
        var forward = camera.global_transform.basis.z
        var right = camera.global_transform.basis.x
        forward.y = 0
        right.y = 0
        forward = forward.normalized()
        right = right.normalized()
        
        var direction = (forward * input_dir.y + right * input_dir.x).normalized()
        velocity.x = direction.x * SPEED
        velocity.z = direction.z * SPEED
        
        # Face the direction of movement
        if direction.length() > 0:
            var target_rotation = atan2(direction.x, direction.z)
            character.rotation.y = lerp(character.rotation.y, target_rotation, 0.1)
            if is_on_floor():
                animation_player.play("walk")
        else:
            velocity.x = move_toward(velocity.x, 0, SPEED)
            velocity.z = move_toward(velocity.z, 0, SPEED)
            if is_on_floor():
                animation_player.play("idle")
        update_animations(direction)
    
    move_and_slide()

Testing Your Setup

  • Press F6 to run the game
  • Use WASD to move the player
  • Move the mouse to rotate the camera
  • W should always move toward where the camera is facing
  • A and D should move left and right relative to the camera
  • Press Space to jump

Troubleshooting Common Issues

  • Camera doesn't follow player: Check that Target is set to the Player node
  • Mouse doesn't rotate camera: Check that mouse is captured (console should show "Mouse captured")
  • Movement feels wrong: Make sure you're using the camera-relative version of the script
  • Player moves in unexpected directions: Check that camera is active and the script is getting the camera correctly
💡 Congratulations! You now have a complete third-person camera system with camera-relative movement!
